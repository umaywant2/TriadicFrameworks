TriadicFrameworks — Engine Prompt Modules

The TriadicFrameworks engine modules provide structured prompt sets for all RTT engines and IPD‑12. Each engine module contains explainers, prompts, diagnostics, worksheets, posters, curriculum material, and cross‑links to the Docsbook and S3 Spine Visualizer.

Engine modules define the core behavior of the TriadicFrameworks canon.
They are used for structural analysis, drift detection, coherence restoration, teaching, and deep‑layer traversal.

This page serves as the overview for all engine‑level prompt modules.

RTT/1 — Foundational Engine

File: engines/rtt1.md
RTT/1 defines the foundational structural operators and the first‑layer traversal rules. It introduces basic drift, coherence, and operator grammar.

RTT/2 — Intermediate Engine

File: engines/rtt2.md
RTT/2 expands the structural stack, introduces multi‑layer traversal, and provides intermediate diagnostics and alignment workflows.

RTT/3 — Advanced Engine

File: engines/rtt3.md
RTT/3 introduces advanced drift patterns, coherence restoration, and multi‑regime structural synthesis. It is used for complex analysis and teaching.

RTT/12 — Full‑Spectrum Engine

File: engines/rtt12.md
RTT/12 provides full‑spectrum structural traversal across all canonical layers.
It includes advanced diagnostics, operator grammar, and cross‑framework alignment.

RTT∞ — Deep‑Layer Engine

File: engines/rtt_infinity.md
RTT∞ exposes the deepest structural stack in TriadicFrameworks: vacuum collapse, substrate‑tensor reconstruction, dimensional rails, prime‑states, infinite regimes, and full bidirectional integration.

RTT∞ includes:

  • vacuum layer
  • substrate‑tensor
  • dimensional rails
  • prime‑states
  • infinite regimes
  • integration maps
  • posters
  • curriculum
  • exams

IPD‑12 — Paradox Engine

Directory: engines/rtt_ipd_12/
IPD‑12 defines paradox traversal, paradox resolution, paradox teaching workflows, and paradox‑aligned diagnostics.
It integrates with RTT engines and the teaching stack.
