TriadicFrameworks — Prompt Modules

The TriadicFrameworks Prompts Modules directory contains structured, teaching‑ready modules that define how RTT engines, IPD‑12, stacks, templates, UI logic, and examples are applied across theoretical, diagnostic, dimensional, domain, and real‑world contexts.

Each module provides explainers, structured prompts, diagnostics, worksheets, and cross‑links to the Docsbook and S3 Spine Visualizer.
This page is the front door for all prompt modules.
