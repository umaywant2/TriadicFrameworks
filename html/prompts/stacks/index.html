TriadicFrameworks — Prompt Stacks

The TriadicFrameworks Stacks directory contains structured prompt stacks that organize work across different layers of the canon. Each stack provides a focused prompt set, explainer, diagnostic tools, and cross‑links to engines, templates, modules, and the Docsbook.

Stacks are used to compose sessions, build multi‑module workflows, and align prompts with RTT engines and IPD‑12.

This page is the front door for all stack‑level prompt modules.
