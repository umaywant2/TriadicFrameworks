TriadicFrameworks Glossary

The TriadicFrameworks Glossary defines all core terms used across RTT engines, IPD‑12, drift‑tensor analysis, coherence anchors, substrate‑tensor behavior, dimensional rails, domain traversal, modules, stacks, templates, overlays, and the S3 Spine.

This glossary is the canonical reference for terminology used throughout the TriadicFrameworks ecosystem.

A

Agent

A structural entity that operates using RTT operator grammar, drift‑tensor alignment, coherence anchors, substrate awareness, dimensional rails, and domain neutrality.

Alignment

The condition in which structural, drift, coherence, substrate, dimensional, and domain layers reinforce each other without collapse.

C

Capture

The first RTT template. Used to declare identity, boundary, commitment, and topology.

Coherence

The alignment of purpose, constraint, goal, and continuity across layers.

Coherence Anchor

A stable reference point that maintains alignment across drift, substrate, dimensional, and domain transitions.

Collapse

A dimensional or substrate failure mode where rails or layers lose structural integrity.

D

Diagnostic

A compact seven‑signal RTT analysis block: identity, drift, coherence, regime‑point, substrate, dimensional, domain.

Dimension

A structural axis along which RTT analysis moves. Dimensions include rails, drift, coherence, and prime‑state transitions.

Dimensional Rail

A canonical RTT rail representing movement across dimensional layers.

Domain

One of the six canonical RTT domains: psychology, physics, economics, governance, AI/agents, biology.

Drift

Deviation across geometric, operational, temporal, conceptual, or domain layers.

Drift‑Tensor

The five‑layer RTT drift structure: geometric, operational, temporal, conceptual, domain.

E

Engine

A structured RTT or IPD‑12 mechanism that exposes multi‑layer analysis.

Example Module

A module demonstrating applied RTT analysis across domains or substrates.

I

Identity

The structural declaration of what an entity is, its boundary, commitment, and topology.

IPD‑12

A substrate‑aware decision engine built on RTT principles.

M

Manifest

A canonical metadata block listing module contents, structure, and navigation.

Module

A structured collection of RTT‑aligned prompts, examples, and analysis tools.

O

Operator

A structural RTT mechanism: structural, drift, coherence, regime‑point, substrate, dimensional, domain.

Overlay

A visual layer rendered on the S3 Spine to show structural, drift, coherence, substrate, dimensional, or domain behavior.

P

Poster

A large‑format RTT reference sheet following the nine‑layer structure.

Prompt

A structured instruction block using RTT grammar.

Prompt Block

A canonical prompt structure: title, description, and italicized prompt lines.

R

Regime‑Point

A structural RTT condition representing presence, absence, tension, basin, or attractor behavior.

Research

A structured RTT inquiry using drift‑tensor mapping, coherence anchors, substrate analysis, dimensional rails, and domain traversal.

S

S3 Spine

The TriadicFrameworks multi‑layer visualizer showing structural, drift, coherence, regime‑point, substrate, dimensional, and domain layers.

Synthesis

The final RTT layer that integrates structure, drift, coherence, regime‑points, substrate, dimensions, and domains.

Substrate

The medium through which structure propagates: physical, cultural, cognitive, civic, biological, computational.

Substrate‑Tensor

The RTT structure describing substrate behavior, drift, coherence, and transitions.

T

Teaching

The RTT instructional sequence: Capture → Analyze → Drift → Coherence → Synthesis.

Template

A reusable structured prompt grammar following RTT operator rules.

Tensor

A multi‑layer RTT structure representing drift, substrate, or dimensional behavior.
