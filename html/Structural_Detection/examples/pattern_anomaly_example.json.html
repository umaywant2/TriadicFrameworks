# pattern_anomaly_example.json — Explanation

## Purpose
Demonstrates a **pattern anomaly**: a repeated motif with a single deformation.

## Structure
- Segments 1 and 2 contain the motif `A → B → A`.
- Segment 3 contains `A → X → A`, where **X** breaks the motif.

## Detection Notes
- **Motif detected:** A‑B‑A  
- **Anomaly:** X replaces B in segment 3  
- **Boundary:** anomaly localized to segment 3  
- **Regime hint:** formal → emergent boundary
