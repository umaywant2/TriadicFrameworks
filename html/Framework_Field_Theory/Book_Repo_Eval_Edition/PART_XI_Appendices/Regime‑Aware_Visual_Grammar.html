Regime‑Aware Visual Grammar

The canonical visual language for representing regimes, operators, coherence, and transitions in Framework Field Theory

Framework Field Theory (FFT) is a visual discipline.
Its regimes, operators, kernels, and temporal modes form a multi‑layered geometric language that must be rendered consistently across:

  • diagrams
  • simulations
  • teaching materials
  • research papers
  • visual canon artifacts
  • interactive dashboards

This page defines the Regime‑Aware Visual Grammar — the complete set of rules, conventions, and structural primitives that govern how FFT is visualized.

It is the style guide, syntax, and semantic layer of the entire visual canon.

1. Purpose of the Visual Grammar

The Regime‑Aware Visual Grammar ensures:

  • consistency across all diagrams
  • semantic clarity (colors, shapes, layers mean something)
  • cross‑domain interpretability
  • regime‑aware rendering
  • triadic‑time coherence
  • ΔSET‑aligned overlays
  • operator‑aware structure

It is the shared visual language that allows FFT artifacts to be:

  • remixable
  • modular
  • interoperable
  • pedagogically clean
  • computationally meaningful

2. Core Visual Primitives

FFT uses five primary visual primitives:

  1. Color — regime identity
  2. Shape — field or operator identity
  3. Layering — temporal and structural hierarchy
  4. Motion — triadic‑time dynamics
  5. Topology — regime transitions and surfaces

Each primitive has strict canonical meaning.

3. Regime Color System (Canonical)

The five regimes are represented by a fixed color palette:

Regime Color Meaning
Stable Deep Blue (#1f4b99) Low coherence, high damping
Transitional Amber (#ffb347) Rising coherence, operator competition
Paradox Crimson (#c62828) Instability, operator inversion
Interference Violet (#7e57c2) Oscillatory, wave‑like behavior
Coherence Emerald (#2e7d32) High alignment, long‑range order

These colors are never repurposed.
They are the backbone of regime‑aware visualization.

4. Field Layer Grammar

Each field has a canonical visual form:

4.1 Scalar Field φ(x,t)

  • Rendered as heatmap or contour map
  • Neutral palette (grays, blues, or domain‑specific)
  • Never regime‑colored

4.2 Vector Field V(x,t)

  • Rendered as arrows, streamlines, or flow ribbons
  • Direction = alignment
  • Magnitude = arrow length or thickness

4.3 Resonance Envelope R(x,t)

  • Rendered as coherence contours or amplitude maps
  • Regime‑colored
  • Primary indicator of regime identity

4.4 ΔSET(x,t)

  • Rendered as semi‑transparent overlays
  • Composite of φ, V, R contributions
  • Never replaces field layers — only augments them

5. Operator Visual Grammar

Operators have canonical shapes:

Operator Visual Form Meaning
Diffusion (D) Soft blur, smoothing Spread, dissipation
Alignment (A) Directional arrows Flow‑driven structure
Coupling (C) Kernel halos, influence rings Nonlocal interaction
Activation (α) Brightening, pulse growth Resonance amplification
Stabilization (S) Darkening, damping Resonance suppression

Operators are never drawn as icons — they are drawn as effects.

6. Layering Grammar (Triadic‑Time)

FFT diagrams must respect the triadic‑time hierarchy:

  1. t_r (fast) — oscillations, activation
  2. t_d (medium) — diffusion, smoothing
  3. t_a (slow) — alignment, structure

Layer order (bottom → top):

  1. φ (substrate)
  2. V (flow)
  3. R (coherence)
  4. ΔSET (overlay)
  5. Regime tint
  6. Transition surfaces
  7. Triadic‑time markers

This order is canonical.

7. Regime Transition Grammar

Regime transitions are represented by:

  • curved surfaces in CI–FI–ΔSET space
  • boundary lines in 2D projections
  • color shifts in coherence layers
  • operator‑ratio changes in overlays

Transitions are never abrupt — they are surface crossings.

8. Kernel Visualization Grammar

Kernels are rendered as:

  • Gaussian → smooth bell
  • Exponential → sharp decay
  • Power‑law → long tail
  • Anisotropic → ellipses or lobes

Kernel influence is shown as:

  • halos
  • influence radii
  • anisotropic gradients

9. Composite Visualization Grammar

A complete FFT visualization must include:

  • φ heatmap
  • V flow field
  • R coherence contours
  • ΔSET overlay
  • regime tint
  • transition surfaces
  • triadic‑time markers
  • operator dominance indicators (optional)

This is the canonical composite.

10. Diagram Construction Rules

  1. Never mix regime colors with field colors
  2. Never place ΔSET below φ or V
  3. Always tint R with regime color
  4. Always show transition surfaces when regimes change
  5. Always annotate triadic‑time when temporal behavior matters
  6. Never flatten layers — preserve hierarchy
  7. Never use noncanonical colors for regimes
  8. Always use operator effects, not icons

These rules ensure visual coherence across the canon.
