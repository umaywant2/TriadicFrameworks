TriadicFrameworks Module Index Skill

Overview

This skill provides structured access to the TriadicFrameworks module registry, including metadata, canonical descriptions, analyzer layers, and module.json manifests.

Endpoints

  • GET /api/modules Returns a list of all modules with metadata.

  • GET /api/modules/{id} Returns full module metadata, including analyzer layers, role enums, coherence markers, and canonical descriptions.
