This file defines a symbol‑based SVG sprite for the 12 IPD‑12 prime states:

2. Icon Design Language

  • Circle → Neutral / Seed / Coherence / Gate / Boundary
  • Up‑triangle → Lift (+1D)
  • Down‑triangle → Collapse (−1D)
  • Diamond → Apex / Anomaly
  • Stroke weight: 2
  • ViewBox: 0 0 24 24
