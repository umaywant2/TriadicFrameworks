4. 🖼️ Poster Set Design Specs

Each poster uses:

  • Large icon
  • RTT triad diagram
  • One‑sentence insight
  • Clean, centered layout
  • Gold accent for Meaning

Poster dimensions: A2 vertical
Typography: Modern geometric sans‑serif
