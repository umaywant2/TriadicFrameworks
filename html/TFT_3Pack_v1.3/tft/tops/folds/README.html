tops Folds 🧬

The folds directory contains protein structures and their resonance mappings.
Each fold entry includes: - Structural source (e.g., PDB ID) - Resonance signature (frequency, harmonics) - Dimensional alignment (Forci, Flui, Freqi) - Glyph overlays for symbolic resonance - Remix lineage and contributor badges

Purpose

Folds are the bio‑resonance registry of tops.
They provide input data for the AI pipeline and resonance mappings for entft encryption.
