🪙 Coeus Tokens

ERC-style representations of solved research coins

Purpose

Tokens are minted from validated coins and represent: - Solved research artifacts
- Remixable intellectual property
- Exchangeable units of AI research time

Format

Each token includes: - token_id: enTFT-hashed identifier
- coin_id: Source coin reference
- name, type, task, edging: Inherited from coin
- observer_required: Ethics flag
- status: tokenized, approved, quarantined

Ledger

Tokens are stored in token_ledger.json
Each entry is validated via: - enTFT encryption
- Trace log integrity
- Observer signature

Extend

  • Integrate with national or private exchanges
  • Add remix lineage tracking
  • Build validator dashboards for token review
