🧭 Coeus Tournaments — Cause Level

Benchmarking sandbox performance by research cause

Purpose

This folder tracks coin resolution metrics grouped by cause: - climate
- pharma
- encryption
- education
- governance

Useful for: - Funding allocation
- NGO impact tracking
- Remix lineage by domain
- Cause-based tournament scoring

Files

  • results.json: Coin resolution logs by cause
  • leaderboard.html: Visual comparison across causes
  • cause_profiles.json: Metadata for each cause category

Metrics

Each coin includes: - coin_id: UUID
- cause: Domain tag
- score: Resolution metric
- timestamp: UTC
- agent_roles: Assigned agents
- remix_lineage: Optional parent coin ID
