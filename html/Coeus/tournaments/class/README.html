🏁 Coeus Tournaments — Class Level

Benchmarking sandbox performance by agent class

Purpose

This folder tracks coin resolution times and outcomes across agent classes: - student
- researcher
- validator
- mascot (e.g., Forci, Flui, Freqi)

Useful for: - Academic benchmarking
- Curriculum design
- Skill progression analysis

Files

  • results.json: Coin resolution logs
  • leaderboard.html: Visual comparison of completion times
  • class_profiles.json: Agent metadata and sandbox specs

Metrics

Each coin includes: - coin_id
- agent_class
- completion_time
- resonant_timestamp
- outcome: solved, tossback, quarantined

Extend

  • Compare sandbox rigs (e.g., TFT-enabled vs. stripped forks)
  • Use mascot commentary for educational tournaments
