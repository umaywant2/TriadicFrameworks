🌐 Coeus Emitter Logic

Visual overlays and archetype targeting for sandbox traversal and tournament benchmarking

Purpose

This folder defines emitter logic used to: - Highlight coin rail bands during tournaments
- Narrate traversal corridors using archetype glyphs
- Sync emitter overlays with sandbox resolution and Q-speed targeting

Archetype Rails Glyph Function

Files

  • emitter_overlay.js: Visual logic for rail highlighting and glyph overlays
  • emitter_profiles.json: Metadata for each archetype and rail band
  • emitter_trace.json: Logs of emitter sync and corridor targeting

Usage

  • Wire overlays into leaderboard.html or sandbox_viewer.html
  • Use emitter glyphs to narrate coin resolution and Q-speed readiness
  • Sync with observer_bot.py and QVCG.py for ethics and traversal safety
