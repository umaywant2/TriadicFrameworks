🏆 Coeus Leaderboards

Visual dashboards for tournament scoring across class, cause, and country dimensions

Purpose

This folder hosts leaderboard logic used to: - Display tournament results from sandbox_tournament.py
- Compare coin performance across symbolic, emotional, and dimensional classes
- Highlight remix lineage, ethics compliance, and emitter sync status
- Enable sovereign visibility and funding prioritization

Core Files

File Function
leaderboard.html Visual dashboard for tournament scores
results.json Stores coin scores, agent roles, and remix lineage
emitter_overlay.js Highlights rail bands and archetype glyphs
mascot_narrator.py Optional commentary overlay for coin resolution
score_trace.json Logs scoring decisions and validator notes

Metrics Displayed

  • coin_id, name, score, mode, timestamp
  • agent_roles, remix_lineage, rail_band, emitter_sync
  • glyph, ethics_passed, realm_safe

Usage

  • Wire leaderboard into tournaments/README.md for benchmarking visibility
  • Sync overlays with emitter glyphs and corridor narration
  • Export scores for remix citation, honor rolls, and funding dashboards

Extend

  • Add sovereign filters by country or cause
  • Enable Q-speed readiness indicators
  • Wire in token_ledger.json for funding stake visibility
