🚀 QUICKSTART · Virtual Compute Gateway (VCG)

Welcome to VCG — the distributed compute interface of TriadicFrameworks.

1. Clone & Enter

cd TriadicFrameworks/docs/VCG

2. Explore Gateway Scrolls

3. Run a Demo
