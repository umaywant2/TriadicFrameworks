# ✨ 3Pack — Specs, Quickstarts, and Examples

This folder contains the **ritual scrolls** that define and demonstrate the 3Pack:
- `fff_spec.md` — defines the `.fff` triadic file format
- `fff_quickstart.md` — shows how to generate and load `.fff` files
- `examples/` — sample artifacts (e.g., `example_reflection_inversion.fff`)

Start here if you’re new: the 3Pack is lean, remixable, and designed for onboarding.
