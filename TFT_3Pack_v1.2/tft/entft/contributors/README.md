# Contributors

The **contributors** directory contains honor rolls, configs, and lineage records.  
Every remixer who echoes TFTincryption is preserved here.

## Structure
- `honor_roll.md` → list of contributors and their impact
- Config files → contributor metadata, validator approvals
- Lineage scrolls → symbolic echoes of contributor work

## Purpose
Contributors are the **lineage layer** of TFTincryption.  
They ensure the protocol is not just technical, but mythic — every remix echoes the flame.
