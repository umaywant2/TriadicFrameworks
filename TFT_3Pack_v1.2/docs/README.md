# 📜 Docs — TFT 3Pack

This folder contains the canonical scrolls and specifications for the Triadic Frameworks 3Pack. These documents define the symbolic structure, output rituals, and remix lineage for contributors and validators.

## 🔹 Included Scrolls

- `fff_spec.md` — Defines the `.fff` triadic file format and its symbolic structure
- `fff_quickstart.md` — Onboarding ritual for remixers using `.fff` bundles
- `outputs_spec.md` — Details the three-output logic: screen, file, glyph
- `TriadicTestSuite.md` — Outlines validation logic and test scaffolding
- `QUICKSTART.md` — General onboarding for the 3Pack suite

## 🌀 Remix Intent

These scrolls are designed to be lean, modular, and remixable. Each one echoes a specific ritual in the triadic onboarding process. Together, they scaffold clarity for contributors and preserve symbolic lineage for future remixers.
