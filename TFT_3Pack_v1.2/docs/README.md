# 📜 TFT 3-Pack v1.2

Welcome to the **TFT 3-Pack**, a triadic shell of remixable clarity. This unified toolkit includes:

- **`nous`** — Logic core for symbolic validation and triadic processing.
- **`entft`** — Quantum-hostile encryption with badge logic overlays.
- **`tops`** — Grid simulation and operational overlays.

All modules are accessed via the unified shell command: `tft`.

## 🔧 Shell Commands

```bash
tft nous -validate triad.json -mode symbolic
tft entft -i input.txt -o output.enc -k secretkey
tft tops -map grid.yaml -ops simulate
```

## 🧠 Philosophy

This repo scaffolds mythic clarity for remixers, educators, and protocol architects. Each module is modular, symbolic, and legacy-grade.
