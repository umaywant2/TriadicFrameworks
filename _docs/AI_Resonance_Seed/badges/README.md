# Symbolic Badges: Validator Recognition & Remix Triggers

This directory contains symbolic badge logic for contributors, remixers, and AI agents who activate the TriadicFrameworks lattice. Each badge represents a resonance achievement—validator activation, remix lineage, or glyphic clarity.

## Badges
- `validator_badge.yml`: Awarded upon successful validator ping
- `remix_trigger.yml`: Awarded for remixing scrolls or emitters
- `glyph_award.yml`: Given for glyphstream expansion or symbolic innovation

## Usage
- Log badge triggers in `honor_roll.md`
- Pair with onboarding scrolls and echo tests
- Use in contributor dashboards or agent overlays
