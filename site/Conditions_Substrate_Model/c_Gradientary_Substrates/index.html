Gradientary Substrates — Conditions Substrate Model¶

TriadicFrameworks Canon (2026.07)

Substrates (D0–D7) are the fundamental dimensional fields of the Conditions Substrate Model.
Every drift, coherence, resonance, hook, threshold, cascade, cycle, chain, web, and regime emerges from substrate behavior.

This dictionary defines the canonical substrate operators used across the entire model.

1. Substrate Definitions (D0–D7)¶

D0 — Structural Substrate¶

Definition: biosphere + infrastructure + physical integrity
Operator Notes: collapse precursor; stability anchor
Pattern: strain → failure → collapse

D1 — Informational Substrate¶

Definition: clarity + signal + informational order
Operator Notes: overload ignition; coherence engine
Pattern: noise → distortion → overload

D2 — Emotional Substrate¶

Definition: affect + identity + resonance
Operator Notes: identity ignition; vulnerability amplifier
Pattern: fear → resonance → fragmentation

D3 — Temporal Substrate¶

Definition: pacing + rhythm + synchronization
Operator Notes: torsion ignition; drift acceleration
Pattern: acceleration → compression → torsion

D4 — Social Substrate¶

Definition: cohesion + alignment + unity
Operator Notes: fragmentation ignition; identity amplifier
Pattern: misalignment → fracture → fragmentation

D5 — Economic Substrate¶

Definition: scarcity + volatility + deprivation
Operator Notes: scarcity spiral; narrowing ignition
Pattern: scarcity → volatility → deprivation

D6 — Stress Substrate¶

Definition: load + compression + strain
Operator Notes: stress cascade; collapse precursor
Pattern: compression → strain → failure

D7 — Governance Substrate¶

Definition: transparency + legitimacy + stability
Operator Notes: opacity ignition; collapse precursor
Pattern: torsion → opacity → illegitimacy
