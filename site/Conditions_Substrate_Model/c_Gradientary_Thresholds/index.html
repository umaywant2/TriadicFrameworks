Gradientary Thresholds — Conditions Substrate Model¶

TriadicFrameworks Canon (2026.07)

Thresholds are the critical inflection points of the Conditions Substrate Model — the exact moments where systems flip into new states.
They define collapse ignition, stability ignition, oscillation ignition, scarcity ignition, and regeneration ignition.

This dictionary defines the canonical threshold operators used across all substrates (D0–D7).

1. Drift Thresholds¶

threshold_drift_narrowing¶

Definition: D0,D5,D1 drift↑
Operator Notes: scarcity ignition
Pattern: narrowing threshold

threshold_drift_oscillation¶

Definition: D1,D7,D5 drift↑↑
Operator Notes: volatility ignition
Pattern: oscillation threshold

threshold_drift_destabilization¶

Definition: D0,D7,D1 drift↑↑↑
Operator Notes: collapse precursor
Pattern: destabilization threshold

threshold_drift_collapse¶

Definition: D0,D1,D5,D7 drift↑↑↑↑
Operator Notes: terminal collapse
Pattern: collapse threshold

2. Coherence Thresholds¶

threshold_coherence_stability¶

Definition: Coh(d_i) > Drift(d_i)
Operator Notes: stability ignition
Pattern: stability threshold

threshold_coherence_expansion¶

Definition: Coh↑↑, Drift↑
Operator Notes: growth ignition
Pattern: expansion threshold

threshold_coherence_peak¶

Definition: C7,C1,C4,C0 coh↑↑↑
Operator Notes: apex stability
Pattern: peak threshold

threshold_coherence_regeneration¶

Definition: Coh↑, Drift↓
Operator Notes: recovery ignition
Pattern: regeneration threshold
