Gradientary Cascades — Conditions Substrate Model¶

TriadicFrameworks Canon (2026.07)

This dictionary defines the canonical cascade operators used across the Conditions Substrate Model.
Cascades represent transitions where drift overtakes coherence and substrates enter motion.

1. Dimensional Cascades (D0–D7)¶

structural_cascade (D0)¶

Definition: strain → failure → collapse
Operator Notes: biosphere + infrastructure failure
Pattern: collapse ignition

informational_cascade (D1)¶

Definition: noise → distortion → overload
Operator Notes: overload ignition
Pattern: volatility precursor

emotional_cascade (D2)¶

Definition: fear → identity → vulnerability
Operator Notes: resonance amplification
Pattern: identity ignition

temporal_cascade (D3)¶

Definition: pacing → acceleration → compression
Operator Notes: temporal torsion
Pattern: drift acceleration

social_cascade (D4)¶

Definition: cohesion → fracture → fragmentation
Operator Notes: cohesion collapse
Pattern: fragmentation ignition

economic_cascade (D5)¶

Definition: scarcity → volatility → deprivation
Operator Notes: scarcity spiral
Pattern: deprivation ignition

stress_cascade (D6)¶

Definition: load → compression → failure
Operator Notes: stress collapse
Pattern: compression ignition

governance_cascade (D7)¶

Definition: transparency → torsion → opacity
Operator Notes: legitimacy collapse precursor
Pattern: opacity ignition
