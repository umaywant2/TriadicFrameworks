Gradientary Drift — Conditions Substrate Model¶

TriadicFrameworks Canon (2026.07)

This dictionary defines the canonical drift operators used across the Conditions Substrate Model.
Drift is the motion field — the force that pulls substrates away from stability and toward cascades, thresholds, and regime transitions.

1. Dimensional Drift (D0–D7)¶

structural_drift (D0)¶

Definition: integrity → strain → failure → collapse
Operator Notes: biosphere + infrastructure drift
Pattern: collapse precursor

informational_drift (D1)¶

Definition: clarity → noise → distortion → overload
Operator Notes: overload ignition
Pattern: volatility precursor

emotional_drift (D2)¶

Definition: trust → anxiety → fear → fragmentation
Operator Notes: identity destabilization
Pattern: identity precursor

temporal_drift (D3)¶

Definition: pacing → acceleration → compression → torsion
Operator Notes: temporal misalignment
Pattern: acceleration precursor

social_drift (D4)¶

Definition: cohesion → misalignment → fracture → fragmentation
Operator Notes: cohesion collapse
Pattern: fragmentation precursor

economic_drift (D5)¶

Definition: balance → scarcity → volatility → deprivation
Operator Notes: scarcity spiral
Pattern: deprivation precursor

stress_drift (D6)¶

Definition: load → compression → strain → failure
Operator Notes: stress cascade
Pattern: compression precursor

governance_drift (D7)¶

Definition: transparency → torsion → opacity → illegitimacy
Operator Notes: legitimacy collapse precursor
Pattern: opacity precursor
