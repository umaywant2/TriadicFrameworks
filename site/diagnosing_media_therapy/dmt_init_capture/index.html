🎬 1. DMT Workflow (Diagnosing Media Therapy)¶

A lightweight, repeatable routine that captures emotional signal through media reactions.

Step 1 — Select Media (User‑Driven)¶

  • User chooses a familiar piece of media:
  • song, movie clip, TV moment, YouTube video, podcast snippet, home video, game scene.
  • Familiarity is key — it anchors the reaction in memory, not novelty.

Step 2 — Engage Briefly¶

  • User listens or watches for 10–30 seconds.
  • No instructions to “analyze.”
  • No pressure to “open up.”

Step 3 — Micro‑Reflection (One Sentence)¶

User gives a short, spontaneous reaction, such as:
- “This feels heavy today.”
- “This reminds me of when I felt stuck.”
- “This scene calms me.”
- “This song makes me feel like I’m moving forward.”

The brevity is the magic — it keeps the signal clean.

Step 4 — AI Captures the Signal (Indirect)¶

AI extracts:
- emotional tone
- resonance layer
- stress markers
- clarity/fog indicators
- identity anchors
- drift signals
- temporal shifts

No interpretation.
No labeling.
Just pattern capture.

Step 5 — Longitudinal Mapping¶

Over time, the system builds:
- emotional trajectories
- stability vs. volatility
- recurring themes
- resilience patterns
- media‑based grounding cues

Step 6 — Optional Sharing with Therapist¶

User can export a pattern summary, not raw reactions.

The therapist sees:
- arcs
- shifts
- themes
- anchors
- stress cycles

Not “data,” but process.

🎼 2. Media‑Reaction Schema (RTT‑Aligned)¶

A simple, structured way to encode each reaction.

Core Fields¶

Field Description
Media Type Song, scene, clip, video, etc.
Media Context Why this media matters to the user (optional).
User Reaction (1–2 sentences) The spontaneous reflection.
Resonance Layer Emotional frequency (calm, heavy, restless, nostalgic, etc.).
Temporal Layer How today’s reaction compares to previous ones.
Triadic Domain Identity, stress, relationships, purpose, coherence, drift, memory, aspiration.
Signal Notes Subtle cues: fog, clarity, avoidance, grounding.

Why this works¶

It’s:
- indirect
- low‑pressure
- high‑signal
- emotionally safe
- universally accessible

It’s RTT applied to everyday media.

🔒 3. Privacy Boundaries (Clear + Humane)¶

DMT must be safe, optional, and user‑controlled.

User Controls¶

  • User chooses all media.
  • User chooses what to say.
  • User chooses what to share.
  • User can delete any entry.
  • User can disable AI pattern tracking at any time.

AI Boundaries¶

  • AI does not diagnose.
  • AI does not label disorders.
  • AI does not interpret trauma.
  • AI does not replace therapy.
  • AI only reflects patterns the user already expressed.

Therapist Boundaries¶

  • Therapists receive summaries, not raw logs.
  • Summaries focus on patterns, not judgments.
  • User decides when and what to share.

Ethical Frame¶

DMT is a reflective tool, not a clinical instrument.

🧑‍⚕️ 4. Therapist‑Facing Interface (Clarity + Utility)¶

A clean dashboard that shows process, not pathology.

Key Panels¶

  • Emotional Trajectory Graph
    Shows how reactions shift over time.

  • Resonance Frequency Map
    Which emotional tones recur.

  • Triadic Domain Distribution
    Which domains the user naturally gravitates toward.

  • Media Anchors
    Media that consistently grounds, lifts, or destabilizes.

  • Temporal Drift Indicators
    Subtle changes in tone, energy, or clarity.

Therapist View Priorities¶

  • No labels
  • No diagnoses
  • No predictions
  • No interpretations

Just patterns, arcs, and themes.

This gives therapists something intake forms never do:
a living map of the user’s inner world.

🧑‍💬 5. User‑Facing Language (Gentle + Accessible)¶

The tone must feel like an invitation, not an evaluation.

Prompts¶

  • “Pick something familiar — a song, clip, or scene.”
  • “Watch or listen for a moment.”
  • “What does it feel like today?”
  • “One sentence is enough.”
  • “There’s no right answer.”
  • “Your reaction can change every time — that’s normal.”
  • “You can delete anything you don’t want saved.”
  • “You choose what to share.”

Reassurances¶

  • “This isn’t analysis — it’s reflection.”
  • “Your reactions belong to you.”
  • “You’re not being judged.”
  • “This is just a way to notice patterns over time.”

Session Summary Language¶

  • “Here’s what’s been steady.”
  • “Here’s what’s been shifting.”
  • “Here are the themes that keep returning.”
  • “Here are the media moments that ground you.”
  • “Here are the ones that stir things up.”
