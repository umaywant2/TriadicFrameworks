Appendix K — Compression & Expansion Maps¶

Canonical maps for dimensional compression, expansion, translation, and cross‑layer coherence in Framework Field Theory¶

Compression and expansion are the dimensional transport mechanisms of Framework Field Theory.
They describe how a framework:

  • compresses into a lower‑dimensional domain
  • expands into a higher‑dimensional domain
  • translates laterally across domains
  • preserves coherence during dimensional movement
  • avoids collapse during downward drift
  • avoids distortion during upward drift

This appendix provides the canonical maps for compression, expansion, and translation across the 0D–9D stack.

1. What Compression & Expansion Are¶

Compression¶

Reducing a framework’s dimensional envelope while preserving identity.

Used for:

  • teaching
  • simplification
  • translation
  • domain adaptation
  • communication

Expansion¶

Increasing a framework’s dimensional envelope to unlock new capabilities.

Used for:

  • evolution
  • generativity
  • coherence upgrades
  • hybridization
  • field‑level integration

Compression and expansion are structural transformations, not metaphors.

2. Compression Map (High‑D → Low‑D)¶

How frameworks compress downward without collapsing¶

9D → 7D → 6D → 5D → 4D → 3D → 2D → 1D → 0D

Compression Rules¶

  1. Coherence compresses into rhythm
    6D → 5D

  2. Rhythm compresses into context
    5D → 4D

  3. Context compresses into transition
    4D → 3D

  4. Transition compresses into relation
    3D → 2D

  5. Relation compresses into lineage
    2D → 1D

  6. Lineage compresses into identity
    1D → 0D

Compression Risks¶

  • oversimplification
  • paradox loss
  • regime flattening
  • coherence collapse

Compression must be guided by a coherence engine.

3. Expansion Map (Low‑D → High‑D)¶

How frameworks expand upward into higher dimensions¶

0D → 1D → 2D → 3D → 4D → 5D → 6D → 7D → 8D → 9D

Expansion Rules¶

  1. Identity expands into lineage
    0D → 1D

  2. Lineage expands into relation
    1D → 2D

  3. Relation expands into transition
    2D → 3D

  4. Transition expands into context
    3D → 4D

  5. Context expands into rhythm
    4D → 5D

  6. Rhythm expands into coherence
    5D → 6D

  7. Coherence expands into meta‑structure
    6D → 7D

  8. Meta‑structure expands into field behavior
    7D → 8D

  9. Field behavior expands into meta‑field evolution
    8D → 9D

Expansion Risks¶

  • paradox overload
  • operator mismatch
  • regime instability
  • coherence saturation

Expansion must be paced by rhythm and coherence.

Translation Rules¶

  1. Preserve dimensional envelope
  2. Preserve operator pattern
  3. Rebuild envelope conditions
  4. Recontextualize paradox
  5. Maintain coherence thresholds

5. Compression–Expansion Cycle (Teaching Mode)¶

The pedagogical loop for dimensional literacy¶

Expand → Explore → Compress → Reframe → Expand

Cycle Steps¶

  1. Expand into a higher dimension
  2. Explore new operators and regimes
  3. Compress into a simpler representation
  4. Reframe the concept
  5. Expand again with new coherence

This is the Learning Spiral (Chapter 23) applied to dimensional movement.

6. Compression Pathways (Diagram‑Ready)¶

Pathway A — High‑D → Mid‑D¶

9D → 7D → 6D → 5D

Used for:

  • simplifying generative engines
  • teaching meta‑coherence
  • translating field behavior

Pathway B — Mid‑D → Low‑D¶

5D → 4D → 3D → 2D

Used for:

  • simplifying processes
  • creating diagrams
  • teaching transitions

Pathway C — Full Compression¶

9D → 0D

Used for:

  • naming
  • identity extraction
  • conceptual distillation

7. Expansion Pathways (Diagram‑Ready)¶

Pathway A — Low‑D → Mid‑D¶

2D → 3D → 4D → 5D

Used for:

  • evolving structural frameworks
  • adding rhythm
  • increasing adaptability

Pathway B — Mid‑D → High‑D¶

5D → 6D → 7D → 8D

Used for:

  • adding coherence
  • enabling hybridization
  • stabilizing paradox

Pathway C — Full Expansion¶

0D → 9D

Used for:

  • building generative fields
  • designing meta‑frameworks
  • evolving entire ecosystems

8. Compression & Expansion Failure Modes¶

Compression Failures¶

  • identity distortion
  • paradox loss
  • regime flattening
  • coherence collapse

Expansion Failures¶

  • paradox overload
  • operator saturation
  • dimensional mismatch
  • collapse cascades

These failures are diagnosed using Appendix I.

Appendix K provides the canonical Compression & Expansion Maps — the structural pathways frameworks use to compress downward, expand upward, translate laterally, and maintain coherence across the full 0D–9D dimensional stack.
