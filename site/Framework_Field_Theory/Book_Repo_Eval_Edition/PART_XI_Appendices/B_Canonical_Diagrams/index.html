Appendix B — Operator Tables¶

Canonical tables for operators, sub‑operators, dimensional behaviors, regime interactions, and coherence functions¶

This appendix provides the complete operator tables for Framework Field Theory.
Each table is designed to be:

  • structurally precise
  • pedagogically clear
  • cross‑referenced with the glossary
  • ready for use in research, teaching, and framework design

Operators are presented in seven tables, one for each operator family, followed by three meta‑tables that show cross‑operator patterns, dimensional mappings, and regime interactions.
