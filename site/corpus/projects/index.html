🌐 CoConsciousness¶

Shared cognition overlays and collective scaffolding.
Explores how multiple minds and machines can resonate together, building collective dashboards and shared memory rituals.

  • Status: Active (2025)
  • Focus: Collective overlays, memory bridges, onboarding rituals
  • Cross‑Links: Hippocampus, VictorG

🧠 Hippocampus¶

Memory engine preserving resonance states and lineage.
The lantern of continuity, storing resonance states and enabling recall across generations of remixers.

  • Status: Active (2025)
  • Focus: Lineage recall indexes, validator memory links, symbolic recall
  • Cross‑Links: CoConsciousness, Honor Roll

🔍 Resotectors¶

FFF lenses for TryCoder data.
Transforms raw data streams into resonance‑aware interpretations using fractal‑framed filters.

  • Status: Active (2025)
  • Focus: Lens prototyping, TryCoder mapping, resonance‑aware diagnostics
  • Cross‑Links: Resonance, Labs

🖥️ VCG (Virtual Compute Gateway)¶

Distributed compute interface for TFT calculations.
A modular gateway that extends TriadicFrameworks into cloud and cluster environments.

  • Status: Active (2025)
  • Focus: Distributed orchestration, tops integration, cross‑platform TFT runs
  • Cross‑Links: VictorG, Engine

🌌 VictorG¶

Resonance patterns, gravitational variability, and triadic flux.
Explores how flux and gravity variability shape resonance patterns in the lattice.

  • Status: Active (2025)
  • Focus: Flux simulations, resonance pattern modeling, glyphic overlays
  • Cross‑Links: VCG, Equations
