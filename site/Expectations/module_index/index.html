Expectations Module Index¶

TriadicFrameworks Canon — Root‑Level Orientation Directory
Location: /docs/Expectations/
Version: 2026‑1.0

Purpose¶

This index provides a structured map of all files in the Expectations module.
It is the front‑door directory for students, researchers, and AI agents entering TriadicFrameworks.

The Expectations module defines:

  • what TriadicFrameworks is
  • what TriadicFrameworks is not
  • what newcomers should expect
  • how to evaluate modules
  • how to contribute
  • where to find sample files
  • how cross‑domain engines connect (FFT, FCG, RF‑Builder, IPD‑12, RTT, GU, Pantheon, Medicine)

5. Module Role in the Canon¶

The Expectations module serves as a booster for:

  • FFT (Framework Field Theory)
  • FCG (Framework Creation Guide)
  • RF‑Builder (Regime‑Field Builder)
  • IPD‑12 (engine block)
  • RTT (Resonance Transport Theory)
  • GU (Geometric Unity)
  • Pantheon (mythic‑structural tiers)
  • Computational Medicine (H‑Med)

It is the orientation anchor for the entire TriadicFrameworks canon.
