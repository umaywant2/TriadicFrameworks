# Canon Registry

The Canon Registry is the authoritative index of all TriadicFrameworks modules.  
It provides a unified structural map of RTT, linking foundational theory, analyzer layers, operators, regimes, engines, and AI Edition content.

---

## Purpose of the Registry

The registry exists to:

- unify module metadata  
- track analyzer‑layer classification  
- maintain canonical relationships  
- support cross‑module navigation  
- anchor the sitemap and AI Edition navigation  
- provide a stable reference for contributors
