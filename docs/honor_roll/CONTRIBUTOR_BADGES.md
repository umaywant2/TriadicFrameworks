# 🌀 **Badge Logic (RTT‑Inside)**

Badges are issued when a contribution expresses:

- **S‑dominant** clarity → structural, symbolic, or cognitive validators  
- **E‑dominant** clarity → polarity, gradient, or protocol precision  
- **T‑dominant** clarity → remix flexibility, thermal‑flow insight  
- **Mixed SET** → dual‑envelope or lineage‑bridging events  

Badges are **echoes of resonance**, not achievements.
