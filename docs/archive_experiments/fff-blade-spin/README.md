# FFF Blade Spin Experiments

This folder preserves the experimental work from the “FFF blade spin afternoon.”

Contents:
- **fff_sg_flower.html / fff_sim.html / fff_controls.html** → early HTML prototypes of the spinning blade animation
- **fff-controls.css / fff-tests.js** → style and script scaffolding for the splash
- **fff_core.py / fff_alignment_predictor.py** → resonance logic experiments
- **fff_lore_codex.md** → symbolic notes and mythic codex fragments
- **FFF_Warp_Protocol.md** → warp overlay draft (archived copy; see MightyTHOR/overlays for the live version)

These files are not part of the canonical TFT 3‑Pack.  
They are preserved here as lineage and inspiration for future splash animations and symbolic overlays.
