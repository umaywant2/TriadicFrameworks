# 📂 TFT + FFF Water‑Station Initiative — Media Kit Checklist
## 1. Press Release
- ✅ Final, proofed press release in **.docx** and **.pdf**
- ✅ Short “media blurb” version (100–150 words) for quick copy‑paste into articles

## 2. Product Fact Sheets
- **Water‑Station Fact Sheet** (1 page)
  - Key specs (capacity, kWh/L, humidity range)
  - Integration options (retrofit, new build)
  - Maintenance cadence
  - MSRP / availability
- **Hybrid AWG‑Tactical Flashlight Fact Sheet** (1 page)
  - Output (liters/day)
  - Light specs (lumens, beam distance, modes)
  - Power (battery life, solar assist)
  - Target deployment regions

## 3. Visual Assets
- **High‑Res Product Photos**
  - Water‑station: lifestyle (installed in home), close‑up, cutaway diagram
  - Flashlight: in‑hand, in‑field, water collection close‑up
- **Infographics**
  - “30‑Year Gap” visual
  - TFT + FFF resonance control schematic
  - Comparative efficiency chart
- **Logos**
  - Full‑color, mono, and transparent background versions
- **Figures from Research Paper**
  - Fig. 1–7 with captions (as per paper)

## 4. Video Assets
- **Promo Cut Video** (final export + social‑optimized versions)
- **B‑Roll Footage**
  - Water‑station in operation
  - Flashlight producing water
  - Deployment scenes (humanitarian context)
- **Interview Clips**
  - Founder explaining the 30‑year gap
  - Engineer on TFT + FFF advantage
  - Humanitarian lead on flashlight deployments

## 5. Backgrounders
- **Company Backgrounder** (TriadicFrameworks mission, history, key milestones)
- **Technology Backgrounder** (TFT + FFF principles, development timeline)
- **Humanitarian Program Overview** (deployment strategy, partners, impact goals)

## 6. Executive Bios
- Founder / CEO
- CTO / Lead Engineer
- Humanitarian Program Director

## 7. Contact Sheet
- Media contact name, title, email, phone
- Spokesperson availability for interviews
- Time zone and preferred scheduling method

## 8. Distribution Package
- All files zipped into a single folder with clear naming conventions:

```
/TFT+FFF_MediaKit
   /PressRelease
   /FactSheets
   /Photos
   /Infographics
   /Logos
   /Figures
   /Videos
   /Backgrounders
   /Bios
   /Contact
```
### 💡 Pro Tip: Host the media kit in a cloud folder with view‑only access and no expiry date — include that link in the press release footer so journalists can grab assets instantly.
