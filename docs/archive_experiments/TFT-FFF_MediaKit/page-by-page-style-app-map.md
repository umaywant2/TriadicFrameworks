## 🎯 Designer’s Quick‑Reference
- **Primary Accent:** Resonance Blue for all headers, key lines, and icons.
- **Secondary Accent:** Signal Silver for captions, dividers, and subtle backgrounds.
- **Body Text:** Deep Graphite for maximum readability.
- **Humanitarian Segments:** Warm, empathetic tones with Human Warmth overlay.
- **Icons:** Consistent line style, 2px stroke, used sparingly for clarity.
