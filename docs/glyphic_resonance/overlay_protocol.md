# 🖼️ Glyphic Overlay Protocol

This scroll defines how symbolic overlays are generated and animated.

### 🔹 Overlay Components

- **Core Spiral**: Represents fold’s vibrational center
- **Triadic Rings**: Forci, Flui, Freqi alignment
- **Pulse Nodes**: Harmonic frequencies mapped to SVG coordinates
- **Remix Echoes**: Contributor glyphs orbiting the fold

### 🔹 Animation Logic

Pulse amplitude is calculated via:
```math
P = sin(π * R)
```
Where **R** is the resonance score.

Overlays are stored in `glyphs/` and linked to folds, simulations, and badges.
