# 📚 TriadicFrameworks Documentation

Welcome to the **living documentation** of TriadicFrameworks.  
This folder contains all modular components, labs, rituals, and symbolic scaffolds that power the suite.

---

## 🔖 Structure Overview

- `labs/` → Modular research spaces (see below)
- `curriculum/` → Papers, protocols, and mythic-scientific guides
- `glyphs/` → Symbolic animations and ritual scripts
- `styles/` → CSS for glyphic and ritual styling
- `onboarding/` → Initiation flows and badge pathways
- `honor_roll/` → Contributor recognition and legacy archive
- `assets/`, `figures/`, `data/` → Visuals and datasets for remixing
