============================================================
                 RESONANCE TIME THEORY (RTT)
                 STUDENT POSTER — LEVELS 1–3
============================================================

RTT/1 — TEMPORAL OPERATORS
------------------------------------------------------------
shift     Move the frame of reference forward or backward.
hold      Stabilize the current moment for inspection.
compare   Contrast two states to reveal change.

Core Pattern:
  hold → shift → compare

Use RTT/1 to describe how something changes over time.

------------------------------------------------------------

RTT/2 — REGIME LITERACY
------------------------------------------------------------
stable        Predictable behavior; patterns repeat.
transitional  System is shifting; edges blur.
divergent     New behavior emerges; old rules break.

Core Pattern:
  identify regime → shift → check regime → compare

Use RTT/2 to understand what mode the system is in.

------------------------------------------------------------

RTT/3 — COHERENCE LAYERS
------------------------------------------------------------
surface       Visible behavior; what you can observe.
structural    Underlying rules shaping the surface.
resonance     Deep tendencies that persist across changes.

Core Pattern:
  surface → structural → resonance → compare across layers

Use RTT/3 to analyze systems with depth, not just sequence.

------------------------------------------------------------

RTT/1 + RTT/2 + RTT/3 = FULL STUDENT FOUNDATION
Operators + Regimes + Layers = Multi‑layer temporal analysis.
