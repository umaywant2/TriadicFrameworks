§ Invariants — INV-OR-001 through INV-OR-004
ID Label Type Statement Formal
INV-OR-001 Opacity Gradient structural Opacity is a continuous parameter ω ∈ [0,1]. Binary assignments are special endpoint cases. ∀S: ω(S) ∈ [0,1]
INV-OR-002 Revelation Threshold structural Revelation occurs iff δ(O) strictly exceeds ω(S). At the boundary δ = ω, the structure is opaque. reveal(S,O) ⟺ δ(O) > ω(S)
INV-OR-003 Opacity Persistence structural ω(S) is a property of S's configuration. Observation does not change ω. ω(S) invariant under change of O
INV-OR-004 Partial Revelation structural Revelation may be partial. Each sub-structure s_i is evaluated independently against δ. ∃s_i,s_j ∈ sub(S): reveal(s_i,O) ∧ ¬reveal(s_j,O)
§ Evaluation Phases
Phase Label Active Ops Description
P-OR-1 init — Import Book 1 kernel + Book 3 SD domain. Assert session context. Verify QMROOT = 0D. No OR operators active.
P-OR-2 measure OR-Ω · OR-Δ Assign structural opacity ω via OR-Ω. Declare observer capacity δ via OR-Δ (SD-Σd substrate). Both must complete before threshold.
P-OR-3 threshold OR-Ρ Gate: evaluate δ > ω. Assign revelation_state. If revealed → jump to reveal. If opaque/threshold → proceed to probe.
P-OR-4 probe OR-Λ Classify sub(S) into S_latent and S_access. Detect structural shadows. Skip if revelation_state = revealed.
P-OR-5 reveal OR-Π Build revelation_map {s_i → state_i}. Set partial_revelation_flag when 0 < |S_access| < |sub(S)|.
P-OR-6 catalogue OR-Π Record revelation_map, ω, δ, state to session log. Flag shadows for Book 3 re-investigation. Emit downstream to Books 5, 6, 8.
