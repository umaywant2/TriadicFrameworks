Core Formal Definitions

Regime Tuple

R = ⟨N_R, E_R, C_R, S_R, α_R, λ_R⟩
N_R = node set of the regime
E_R = enforcement relation set
C_R = constraint set (regime enforces)
S_R = governed structure set
α_R ∈ [0,1] = initial authority measure
λ_R ∈ (0,1) = authority decay rate

Authority Decay Function

d(α, n) = α · (1 − λ_R)^n
where n = number of enforcement cycles without observed compliance
Monotonically decreasing; approaches 0 asymptotically; no natural recovery

Constraint Legitimacy

challenge_legitimate(S, C, R) ⟺ challenge_path(S, C, R) ⊆ declared_channels(R)
declared_channels(R) ∈ { formal_objection, appeal, renegotiation, exit }
