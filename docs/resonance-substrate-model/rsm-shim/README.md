# RSM Minimal Shim

This folder contains a minimal reference implementation of the 
Resonance Substrate Model (RSM). It is not a simulator. Instead, it 
demonstrates how to:

- load the RSM schemas
- validate a simulation configuration
- construct a minimal substrate object
- show the structural flow of an RSM evaluation

This shim exists so researchers, automated systems, and AI evaluators 
can interact with the RSM in a lightweight, machine-readable way.

## Usage

python validate.py example_sim.json
python rsm.py example_sim.json
