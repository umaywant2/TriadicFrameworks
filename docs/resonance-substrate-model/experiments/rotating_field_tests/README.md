# Rotating Field Tests

This directory contains experiments involving rotating fields, paradox‑class behavior, and dynamic field interactions.

These experiments may include:
- rotating‑magnet and stationary‑conductor analogs
- spin‑field response to rotating boundary conditions
- resonance envelope deformation under rotation
- stability and coherence measurements

A `.keep` file preserves this directory until rotating field tests are added.
