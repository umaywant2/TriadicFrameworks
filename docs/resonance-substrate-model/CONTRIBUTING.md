# Contributing Guidelines  
This document describes the process for contributing to the Resonance Substrate Model repository.  
All contributions must support reproducibility, clarity, and scientific transparency.

---

## 1. Code of Conduct
Contributors are expected to:
- communicate respectfully and constructively  
- provide clear reasoning for changes  
- support claims with data, derivations, or references  
- avoid personal attribution or self‑promotion in scientific materials  

---

## 2. Contribution Types
The project accepts the following contribution categories:

### 2.1 Documentation
- theoretical explanations  
- method descriptions  
- experiment protocols  
- schema definitions  
- diagrams and figures  

### 2.2 Code
- numerical solvers  
- simulation modules  
- analysis tools  
- visualization utilities  

### 2.3 Data
- raw experimental datasets  
- processed datasets  
- calibration files  
- validation benchmarks  

### 2.4 Experiments
- replication reports  
- apparatus improvements  
- measurement techniques  
- error analysis  

### 2.5 Papers and Supplementary Material
- whitepaper edits  
- derivation corrections  
- reference additions
