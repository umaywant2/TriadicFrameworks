$$\mathcal{E} = (V,\; \rho_q,\; \nabla \Phi)$$

### 2.3 Temperature field $$\mathcal{T}$$

$$\mathcal{T} = (T_{\text{hot}},\; T_{\text{cold}},\; \nabla T)$$

- $$T_{\text{cold}}$$: low‑energy regions (voids, background, sinks)
