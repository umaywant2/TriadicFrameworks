# **3. EDUCATIONAL MODE FEATURES**

Educational Mode adds a set of **non‑intrusive overlays** to the base game.

---

## **3.1 Guided Lenses**
Each Lens gains an **educational overlay**:

- **Structural Lens:** highlights logic patterns, symmetry, invariants  
- **Resonant Lens:** shows behavioral tendencies, emotional cues  
- **Temporal Lens:** reveals recursive structures, loops, dependencies  
- **Paradox Lens:** identifies contradictions, hidden assumptions  

Each overlay includes:

- micro‑lessons  
- reflection prompts  
- teacher‑mode explanations  

---

## **3.2 Drift Dashboard (Student Reflection Tool)**
A simplified Drift readout shows:

- curiosity  
- patience  
- rhythm  
- exploration  
- persistence  

Students reflect on:

- how they approached puzzles  
- how their behavior shaped the world  
- how patterns changed over time  

This becomes a **self‑assessment instrument**.

---

## **3.3 Teacher Console**
A separate interface for educators:

- track student Drift profiles  
- view puzzle completion paths  
- monitor time‑loop usage  
- assign realm‑specific challenges  
- export learning summaries  

The console never judges — it reveals patterns.

---
