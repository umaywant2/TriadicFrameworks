1. **Composition** — gases, aerosols, particulates, ions  
2. **Forcing** — solar, lunar, rotational, orbital drivers  
3. **Dynamics** — flow, turbulence, convection, shear  
4. **Thermodynamics** — heat transfer, latent heat, radiative balance  
5. **Hydrospheric Coupling** — ocean/land/water resonance  
6. **Regime Transitions** — storms, fronts, cyclogenesis  
7. **Resonance & Coherence** — planetary waves, oscillations, teleconnections  

Each phase is mapped across **micro → meso → macro → mega** scales.
