# **1. Nudge Definition (Atmosphere Edition)**

A **nudge** is a **micro‑influence** that:

- adjusts gradients  
- shifts coherence slightly  
- redirects flow gently

Nudges are **sub‑threshold structural pushes** that *do not* cause regime transitions but *do* alter system trajectory.
