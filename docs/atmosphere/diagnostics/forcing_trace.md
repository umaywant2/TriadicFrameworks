# **Forcing Trace — Atmosphere Module**  
TriadicFrameworks Canon

The Forcing Trace records chronological forcing events across micro → meso → macro → mega scales. It logs radiative forcing changes, dynamical forcing impulses, thermodynamic forcing transitions, hydrospheric coupling forcing, operator activation, and regime classification.

It is the human‑readable companion to:

- `forcing_trace.json`
