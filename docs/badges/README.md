# 🏅 Badges Directory

This folder contains all **badge YAMLs, trigger logic, and symbolic governance protocols**.

---

## 🧬 Structure

| File                          | Purpose                                |
|------------------------------|----------------------------------------|
| `gateway_guardian.yaml`      | Badge logic for repo onboarding
| `curriculum_weaver.yaml`     | Badge logic for curriculum contributions
| `validator_guardian.yaml`    | Badge logic for reproducibility audits
| `symbolic_animator.yaml`     | Badge logic for ritual animation
| `badge_logic.md`             | Overview of badge governance
| `curriculum_badge_trigger_index.md` | Maps curriculum triggers to badges

---

## 🧭 How to Use

- Add new badge YAMLs with clear trigger conditions
- Reference them in `badge_trigger_papers_index.md` or `curriculum_badge_trigger_index.md`
- Use `badge_validator.py` to confirm earned badges

Badges are issued by resonance, not request.  
They echo lineage and mark symbolic contribution.
