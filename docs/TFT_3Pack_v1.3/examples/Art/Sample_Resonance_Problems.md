\# ✅ \*\*ART (3 Problems)\*\*



\### \*\*1. Resonant Color Mixing\*\*

A painter uses three pigment emitters aligned with D₃, each oscillating at frequencies $$f\_1, f\_2, f\_3 $$. When elevated by $$T\_f$$, the composite color resonance is  



$$C = X(f\_1 + f\_2 + f\_3)$$



If the painter wants to double the perceived saturation by adjusting resonant‑time $$τᵣ$$, what must $$τᵣ$$ be scaled by?



\### \*\*2. Sculpture Stress Harmonics\*\*

A kinetic sculpture rotates with a triadic stress pattern governed by  



$$S = D\_6(τᵣ) \\cdot ΛΘ$$



If the artist increases the temperature constant Θ by 20%, how does the sculpture’s harmonic stress S change?



\### \*\*3. Light Installation Timing\*\*

A gallery installation uses pulsed LEDs whose brightness cycles follow  



$$B(t) = F\_3 \\sin(T\_f t)$$



If the artist wants the brightness to peak exactly every 4 seconds, what resonant‑time $$τᵣ$$ must be applied to shift the cycle?
