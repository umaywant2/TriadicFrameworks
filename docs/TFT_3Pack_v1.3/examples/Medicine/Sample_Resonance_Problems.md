# ✅ **MEDICINE (3 Problems)**

### **1. Drug Resonance Half‑Life**
Half‑life is  

$$t_{1/2} = \frac{\ln 2}{ΛΘ}$$

If Θ decreases by 10%, how does $$t_{1/2}$$ change?

### **2. Heart Rhythm**
Heart rhythm is modeled as  

$$R = T_f D_3$$

If T_f increases by 8%, what is the percent change in R?

### **3. Dose Response**
Response is  

$$S = \frac{X}{1 + e^{-τᵣ}}$$

If τᵣ increases, how does S change qualitatively?
