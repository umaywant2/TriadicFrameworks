## Diagram 1 – Conceptual coherence (Problem 1)

**Nodes:**

- Frequency elevation: $$T_f$$
- Resonant-time: $$τ_r$$
- Coherence: $$C = T_f / τ_r$$

**Flow:**

1. $$T_f$$ enters a division node.
2. $$τ_r$$ enters the denominator.
3. Output is $$C$$.
4. A control arrow adjusts $$τ_r$$.
