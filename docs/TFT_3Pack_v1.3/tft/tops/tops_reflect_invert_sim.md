# 📜 Triconceptual Viewer: Reflection, Inversion, Simulation

## Purpose
To simulate perception across three symbolic modes:
- **Direct View**: Multi-angle observation
- **Reflective View**: Mirrored perspectives
- **Inverted View**: Geometric and symbolic inversion

This framework reveals emergent properties, hidden harmonics, and symbolic echoes that traditional analysis overlooks.

## Modules
- `direct_view.py`: Rotates glyphs across angles
- `reflective_view.py`: Mirrors glyphs across axes
- `inversion_logic.py`: Symbolically inverts geometry and logic
- `tops_session.py`: Runs unified simulation
- `glyph_compare.py`: Visualizes and compares outputs

## Invocation
```bash
python tops_session.py
python glyph_compare.py
```
