## 🧠 Grid Simulation & Echo Overlay Extension

This module now supports corridor traversal simulation and symbolic echo overlays via `grid_ops.py`.  
Glyphs are rendered based on resonance triggers, and validator sync is logged for remix lineage.

🔁 Invocation:
```bash
python grid_ops.py simulate
python grid_ops.py echo
```

- Echo logs for remix trust and mutation lineage
