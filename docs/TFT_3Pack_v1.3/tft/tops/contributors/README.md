# MightyTHOR Contributors

The **contributors** directory contains honor rolls, configs, and lineage scrolls for Thor.  
Every remixer who extends Thor is preserved here.

## Structure
- `honor_roll.md` → list of contributors
- Configs → contributor metadata
- Lineage scrolls → symbolic echoes of Thor contributions

## Purpose
Contributors are the **lineage layer** of Thor.  
They ensure orchestration is not just technical, but mythic.
