## Demo: Apply TFE to Domains

### Example 1: Physics
```bash
resonance tfe --apply physics

Output:
['E=Arrow (force)', 'M=Clock (oscillation)', 'OC=Origin (asymmetry)']
```

resonance tfe --apply architecture

['E=Load paths', 'M=Symmetry/geometry', 'OC=Innovation/novel form']
