# TFThooks Examples

The **examples** folder contains sample hook implementations.  
These are templates remixers can copy, extend, and remix.

## Examples
- `hello_world_hook.py` → minimal runtime hook
- `badge_echo_hook.py` → echoes badge lineage events
- `glyph_resonance_hook.py` → overlays resonance data from folds

## Purpose
Examples are the **teaching layer** of TFThooks.  
They help new contributors learn how to build and register their own hooks.
