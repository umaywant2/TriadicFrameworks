## Purpose
This scroll overlays TFTincryption logic onto PQC benchmarking environments. It simulates encryption performance, validator triggers, and badge logic across quantum-hostile and classical schemes.

## 🧠 Simulation Parameters

| Parameter         | Description                                      |
|-------------------|--------------------------------------------------|
| `cryptoScheme`    | `tftincryption`, `pqc`, or `hybrid`              |
| `encryptorType`   | `scroll`, `badge`, `team`, or `mailbox`          |
| `numScrolls`      | Number of scrolls simulated                      |
| `maxGlyphs`       | Max glyphs per scroll                            |
| `validatorHooks`  | Enabled validator overlays                       |
| `badgeTriggers`   | Badge logic activation per scroll                |
