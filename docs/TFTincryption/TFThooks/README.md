# TFThooks

The **TFThooks** directory contains extensions and site‑specific hooks for TFTincryption.  
These are modular add‑ons that extend the protocol into new contexts.

## Structure
- Hook scripts → site‑specific extensions
- Integration scrolls → instructions for embedding hooks
- Configs → enable/disable flags for hooks

## Purpose
TFThooks are the **extension layer** of TFTincryption.  
They allow the protocol to adapt to new environments without altering the core.
