# 🧪 Materials — Substrate & Structural Classification

The `materials` directory contains documents that classify, describe, and analyze substrate materials used across TriadicFrameworks.  
These modules define how physical, conceptual, and resonance‑aligned materials behave within RTT mechanics.

Materials modules support:

- substrate classification  
- resonance‑aligned material behavior  
- structural mapping  
- fabrication and dimensional integration  
- cross‑domain material taxonomy  

---

## 📄 Included Materials Files

### `SC_Classification.md`
The **Substrate Classification (SC)** document.  
Defines:

- substrate categories  
- resonance properties  
- dimensional compatibility  
- drift/coherence thresholds  
- material behavior across RTT operator loops  

This is the canonical reference for understanding how materials interact with TriadicFrameworks structures.
