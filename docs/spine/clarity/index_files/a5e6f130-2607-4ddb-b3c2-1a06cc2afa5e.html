C‑N‑R Triad — Quick Reference

The C‑N‑R Triad models every communicative payload φ along three orthogonal axes: Compression (C) measures how tightly meaning is packed, Nuance (N) captures the granularity of distinctions preserved, and Resonance (R) gauges how well the message integrates across diverse receivers.

The composite score Ξ (Xi) blends these three metrics with domain-specific weights to produce a single clarity readiness number — payloads scoring Ξ ≥ 0.70 are considered ship-ready.

Torsion τ represents internal contradictions that can override the regime classification — resolve torsion with the mediation operator M̂ before applying corrective operators.
