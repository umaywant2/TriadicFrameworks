Overview

The Substrate Overlay evaluates the foundational capacity layer beneath active regimes. The Stability Basin Cartographer scores each basin for capacity (C), Saturation Index (SI), and depletion rate (DR), then projects how long the substrate can sustain current regime activity at the observed drift velocity. The Crystal Mycelial Engine models substrate flow through distributed networks, identifying bottleneck nodes and isolated channels.
