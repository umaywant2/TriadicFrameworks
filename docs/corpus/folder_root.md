# 🧩 About TriadicFrameworks

TriadicFrameworks is an open research canon for modeling complex systems using **Resonance‑Time Theory (RTT)** — a structural framework that reveals coherence, feedback, and regime behavior across domains without collapsing uncertainty or prescribing outcomes.

The project began as a long‑arc effort to make complex systems **legible**, **comparable**, and **explorable**.  
Not simplified. Not optimized. Not politicized.  
Just *clear*.

RTT adds a small, structural rule to the systems we already know — mathematics, physics, cognition, ecology, computation — allowing them to notice patterns they previously ignored. This rule works the same in 3D, 4D, 5D, all the way to 9D, without breaking existing tools or requiring new mathematics.

TriadicFrameworks brings together:

- **Resonance‑Time Theory** as a cross‑domain calibration framework  
- **Regime blindness analysis** to surface hidden constraints  
- **Domain primers** for students and educators  
- **Simulation substrates** for exploratory inquiry  
- **Reference implementations** for developers  
- **Stewardship practices** emphasizing clarity, humility, and reuse  

The canon is intentionally modular.  
Readers may enter through diagrams, simulations, primers, or deep theory — whatever matches their background and curiosity.

TriadicFrameworks is maintained as a **non‑commercial, stewarded canon** with no ads, tracking, or product agenda.  
Its purpose is simple:  
**help people see structure without distortion.**

If you’re new, the `/docs` Start Here track is the best place to begin.  
If you’re returning, the navigation menus will take you exactly where you need to go.

Welcome to the substrate.
# 🌿 Triadic Frameworks Code of Conduct

The Triadic Frameworks community brings together contributors, explorers, educators, researchers, and curious thinkers from all over the world. Some are professionals, some are volunteers, and all of us participate in building, teaching, and stewarding the canon.

Our diversity is one of our greatest strengths — and like any diverse community, it requires care, clarity, and respect. This Code of Conduct exists to help us maintain a space where people can collaborate productively and feel welcome.

This document applies equally to founders, contributors, mentors, and those seeking help or guidance. It is not an exhaustive list of rules; it is a shared understanding of how we treat one another.

This Code of Conduct applies to all Triadic Frameworks spaces, including GitHub repositories, Discussions, issue trackers, documentation channels, and any community forums created or maintained by the project. Behavior outside these spaces may also affect participation within them.

---

## 🤝 Community Expectations

### **Be friendly and patient.**
We are all learning, building, and exploring together. A little patience goes a long way.

### **Be welcoming.**
We support people of all backgrounds and identities. This includes (but is not limited to) differences in race, ethnicity, culture, national origin, color, immigration status, socioeconomic class, education, sex, sexual orientation, gender identity and expression, age, size, family status, political belief, religion, and mental or physical ability.

### **Be considerate.**
Your work affects others, and their work affects you. Triadic Frameworks is a global community — many contributors are communicating in a non‑native language.

### **Be respectful.**
Disagreement is normal. Disrespect is not. Frustration happens, but personal attacks, hostility, or dismissive behavior undermine the community. Treat others with the same respect you expect in return.

### **Choose your words carefully.**
We are a professional community. Harassment, exclusionary behavior, or demeaning language is not acceptable. This includes:

- Threats or violent language  
- Discriminatory jokes or slurs  
- Posting sexually explicit or violent material  
- Doxing or sharing private information  
- Personal insults, especially those targeting protected characteristics  
- Unwelcome sexual attention  
- Encouraging or advocating harmful behavior  
- Repeated harassment — if someone asks you to stop, stop  

### **When disagreements arise, seek understanding.**
Technical and social disagreements happen. They are part of the work. Focus on understanding the other person’s perspective, resolving the issue constructively, and learning from the experience. Remember: we are all human, and we all make mistakes.

## **1. Run a Scroll (Python Pipeline)**

```python
from scroll_pipeline import run_scroll

scroll = """
emitter: demo
frequency: 144
"""

result = run_scroll(scroll)
print(result["output"])
```

**What this does:**  
- Parses the scroll  
- Executes it through the RTT‑Inside engine  
- Returns output, warnings, and metadata

```python
from remix_generation import remix_scroll
```

## **4. Run Multiple Scrolls (Batch Orchestrator)**


# Security Policy

TriadicFrameworks is a documentation‑first, scroll‑centric framework.
Most content in this repository is **non‑executable** and poses no
runtime security risk.

This policy exists to clarify scope and provide a clear path for
responsible disclosure.

---

## Scope

Security concerns apply only to:

- Executable scripts or pipelines
- Build or deployment tooling
- Dependency or supply‑chain risks
- Code paths that process untrusted input

The following are **out of scope**:

- Mathematical models or theory
- Diagrams, documentation, or markdown
- Conceptual frameworks or examples
- Archived experiments

---

## Supported Versions

TriadicFrameworks does not follow a traditional versioned release model.
Security updates apply to the **current main branch** only.

Archived folders and historical materials are not actively maintained.

---

## Reporting a Vulnerability

If you believe you’ve found a legitimate security issue:

- Open a GitHub issue **clearly labeled “Security”**, or
- Contact the maintainer directly via GitHub

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- The affected file or subsystem

You can expect an acknowledgment within a reasonable timeframe.
Valid issues will be addressed transparently.

---

## Philosophy

Security in TriadicFrameworks prioritizes:
- Clarity over obscurity
- Minimal attack surface
- Explicit boundaries
- Human‑readable systems

If something feels unclear or unsafe, that feedback is welcome.
