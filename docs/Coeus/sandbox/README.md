# 🧪 Coeus Sandbox  
Isolated environment for multi-agent orchestration

---

## Core Scripts

- `launch_sandbox.py`: Initializes agents and assigns roles  
- `mint_coin.py`: Creates new coin stubs  
- `logs/`: Stores trace logs for reproducibility

---

## Features

- enTFT encryption  
- Dual observer protocol  
- Tossback logic for unsolved coins  
- Full trace logging per coin
