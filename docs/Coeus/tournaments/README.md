# 🏁 Coeus Tournament Layer  
Benchmarking coin resolution across class, cause, and country dimensions

---

## Purpose

This folder orchestrates performance tracking for sandbox coins using three tournament modes:
- `class` — symbolic, emotional, dimensional, etc.  
- `cause` — encryption, climate, education, governance, etc.  
- `country` — geopolitical origin or remix territory

Useful for:
- Remix lineage scoring  
- Validator dashboards  
- Funding allocation and remix rights  
- Sovereign visibility across domains

---

## Subfolders

| Folder | Function |
|--------|----------|
| `class/` | Benchmarks by coin class (symbolic, emotional, etc.)  
| `cause/` | Benchmarks by research cause (climate, encryption, etc.)  
| `country/` | Benchmarks by geopolitical origin (US, JP, IN, etc.)  
| `emitter/` | Visual overlays and archetype targeting for rail logic

---

## Core Files

| File | Purpose |
|------|---------|
| `sandbox_tournament.py` | Runs tournament logic and scores coins  
| `results.json` | Stores tournament results for dashboards  
| `leaderboard.html` | Visual comparison across tournament dimensions  
| `emitter_overlay.js` | Highlights rail bands and emitter glyphs  
| `emitter_profiles.json` | Metadata for emitter archetypes  
| `emitter_trace.json` | Logs emitter sync and corridor targeting

---

## Metrics

Each coin is scored based on:
- `coin_id`, `name`, `mode`, `score`, `timestamp`  
- `agent_roles`, `remix_lineage`, `rail_band`, `emitter_sync`
