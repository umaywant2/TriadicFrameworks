# 🧭 Coeus Tournaments — Cause Level  
Benchmarking sandbox performance by research cause

---

## Purpose

This folder tracks coin resolution metrics grouped by cause:
- `climate`  
- `pharma`  
- `encryption`  
- `education`  
- `governance`

Useful for:
- Funding allocation  
- NGO impact tracking  
- Remix lineage by domain

---

## Files

- `results.json`: Coin resolution logs by cause  
- `leaderboard.html`: Visual comparison across causes  
- `cause_profiles.json`: Metadata for each cause category

---

## Metrics

Each coin includes:
- `coin_id`  
- `cause`  
- `completion_time`  
- `resonant_timestamp`  
- `outcome`: `solved`, `tossback`, `quarantined`
