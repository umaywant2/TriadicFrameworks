# 🎙️ Coeus Tournaments — Mascot Commentary  
Narration logs from Forci, Flui, and Freqi during sandbox tournaments

---

## Purpose

This folder stores mascot commentary for:
- Coin decomposition  
- Tournament outcomes  
- Rail resonance scans  
- Remix lineage observations

---

## Files

- `commentary_logs.json`: Timestamped mascot quotes  
- `layer_switches.json`: Logs of layer toggles during emitter scans  
- `mascot_profiles.json`: Voice styles, rail affinities, and emotional triggers

---

## Usage

- Narration triggered by `mascot_narrator.py`  
- Commentary visualized in `resonance_mapper.html`  
- Logs used for educational replay, remix citation, and symbolic annotation
