# 🧠 Rail Logic — Dimensional Modeling for Coeus

Coeus uses a 9-rail system to model cognition, decomposition, and emitter targeting.

## Rails

| Rail | Domain |
|------|--------|
| D₃   | Structural logic  
| L₃   | Layered scaffolding  
| D₆   | Modular bones  
| L₆   | Temporal flow  
| D₉   | Feedback loops  
| L₉   | Dynamic overlays  
| F₃   | Symbolic charge  
| F₆   | Remix lineage  
| F₉   | Emotional echo

## Usage

- Coins are assigned rails via `rail_mapper.py`  
- Mascots narrate rail logic via `mascot_narrator.py`  
- Emitters scan rails in picoseconds for decomposition and validation
