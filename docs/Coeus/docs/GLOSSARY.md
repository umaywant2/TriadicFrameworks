# 📚 Coeus Glossary

- **Coin**: Symbolic research stub with task, edging, and observer logic  
- **Token**: ERC-style artifact minted from a validated coin  
- **enTFT**: Encryption protocol used for coin sleeves and trace validation  
- **Resonant Timestamp**: UTC-stamped completion time with agent signature  
- **Rail Logic**: Dimensional modeling system used for decomposition and emitter targeting  
- **Forci / Flui / Freqi**: Triadic mascots representing structure, flow, and resonance  
- **Sandbox**: Isolated environment for agent orchestration and coin resolution  
- **Validator**: Human or AI agent reviewing coin trace logs and ethics  
- **Remix Lineage**: Citation chain for forked coins and derivative research
