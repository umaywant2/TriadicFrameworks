## Remix Principles

- **Lineage First** — all remixes must cite original coin ID and trace log  
- **Mutation Declared** — remixers must declare mutation type (`symbolic`, `dimensional`, etc.)  
- **Rights Inherited** — remix rights are defined in `coin_templates.json`  
- **Validator Enforced** — `validator_bot.py` and `professor_bot.py` audit remix logic  
- **Remix Ledger** — remix lineage is archived in `score_trace.json` and `honor_rolls.md`

---

## Remix Ritual

1. Select a coin with `remix_rights.allowed = true`  
2. Declare mutation type and remix intent  
3. Cite original coin ID in `remix_lineage`  
4. Validate ethics, realm safety, and emitter sync  
5. Submit for validator and professor audit  
6. Mint as sovereign token via `token_minter.py`
