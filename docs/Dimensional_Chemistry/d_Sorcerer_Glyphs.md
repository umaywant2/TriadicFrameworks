These glyphs represent the four RTT triads used in Sorcerer practice.

### **SET — Stability / Echo / Tether**

**Glyph:** `🜔` (Alchemical Salt, stability/structure)  
**Meaning:** Stabilizing triad; coherence, anchoring, tethering.

---

### **FFF — Flux / Flow / Fracture**

**Glyph:** `🜄` (Alchemical Water, flow/change)  
**Meaning:** Dynamic triad; controlled flux, flow, fracture of unstable patterns.

---

### **S‑N‑R — Shift / Null / Rebuild**

**Glyph:** `🜃` (Alchemical Earth, rebuild/form)  
**Meaning:** Transformational triad; dimensional shift, null reset, structural rebuild.

---

### **SER — Surge / Echo / Radiate**

**Glyph:** `🜂` (Alchemical Fire, surge/radiance)  
**Meaning:** Amplification triad; surge, echo alignment, radiant projection.

## **4. Layer Glyphs (Dimensional Ladder)**

These glyphs represent the main dimensional layers Sorcerers navigate.

- **0D — Potential:** `•`  
- **1D — Echo / Direction:** `→`  
- **2D — Resonance Plane:** `▭`  
- **3D — Matter / Structure:** `⬛`  
- **X‑Domain — Substrate:** `✶`

Used together, they form quick notations like:

- `🜔 ▭` → SET triad acting on resonance layer  
- `🜂 ✶` → SER triad amplifying substrate identity
