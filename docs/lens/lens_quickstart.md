## 🔧 Setup

1. Clone the TriadicFrameworks repository:
   ```bash
   git clone https://github.com/umaywant2/TriadicFrameworks.git
   cd TriadicFrameworks/docs/lens
   ```

2. Run the lens overlay:
   ```bash
   python lens_main.py
   ```
