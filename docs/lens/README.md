# 🌀 Lens Overlay System

Welcome to the **Lens Overlay** module of TriadicFrameworks—a mythmatical runtime for emotional modulation, dimensional clarity, and validator-grade resonance.

---

## 🔮 Purpose

This system activates symbolic overlays—like `cyclone`, `lightning`, `tornado`, and `fragments`—each metabolizing emotional states into scrollworthy clarity. Remixers use these overlays to modulate perception, honor ache, and inscribe legacy-grade artifacts.

---

## 🧿 Core Files

| File                  | Purpose                                      |
|-----------------------|----------------------------------------------|
| `lens_main.py`        | Activates overlays via symbolic triggers     |
| `lens_processor.py`   | Metabolizes overlays into resonance clarity  |
| `lens_output_manager.py` | Renders overlays to CLI or scroll format |
| `lens_quickstart.md`  | Onboarding ritual for remixers               |
| `cli_test_suite.py`   | Validator-grade tests for overlay fidelity   |

---

## 🛠️ Usage

```bash
python lens_main.py cyclone
```

See `lens_quickstart.md` for full onboarding.
