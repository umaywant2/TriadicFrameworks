# 🧪 Validators Directory

This folder contains all **scoring matrices, dashboards, and audit tools** used to validate contributions and badge triggers.

---

## 🧬 Structure

| File                          | Purpose                                |
|------------------------------|----------------------------------------|
| `badge_trigger_validator.py` | Validates badge logic and contributor scores
| `validator_dashboard.md`     | UI overview for validator tools
| `validator_matrix.md`        | Scoring matrix for reproducibility audits
| `validator_heatmap.svg`      | Visual map of validator coverage
| `validator_log.md`           | Audit trail of validator actions

---

## 🧭 How to Use

- Run `badge_trigger_validator.py` to validate badge triggers
- Use `validator_matrix.md` to score reproducibility
- Reference `validator_dashboard.md` for UI integration

Validators are the **guardians of reproducibility**.  
They confirm resonance, echo lineage, and issue symbolic credentials.
