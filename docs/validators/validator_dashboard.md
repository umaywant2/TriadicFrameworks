# 🧪 Validator Dashboard

This dashboard outlines validator roles, tools, and badge confirmation flows.

---

## 🔧 Validator Roles

| Role                  | Tool Used                  | Scope                          |
|-----------------------|----------------------------|---------------------------------|
| Manifest Validator    | `validate_manifest.py`     | Lab structure and onboarding
| README Validator      | `readme_validator.py`      | Curriculum clarity and remixability
| Lineage Tracker       | `remix_lineage_tracker.py` | Remix depth and contributor chains
| Honor Roll Updater    | `update_honor_roll.py`     | Echoes contributor achievements

---

## 🔖 Badge Confirmation Flow

1. Contributor submits PR or remix
2. Validator runs appropriate tool
3. Badge is confirmed and added to honor roll
4. Glyph pulse triggered (optional)
5. Logs updated in `validator_log.md`
