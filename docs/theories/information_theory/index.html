Focus: Information Theory is examined through the TriadicFrameworks pillars of Entropy, Channel, and Compression — the three structural elements of Shannon's 1948 framework that remain the foundation of every digital communication system, data storage technology, and AI model today.

This module covers Shannon entropy, mutual information, the noisy-channel coding theorem, source coding, algorithmic (Kolmogorov) complexity, and rate-distortion theory, with cross-module resonances to Thermodynamics, Quantum Mechanics, Evolutionary Biology, and Chaos Theory.

Triadic Pillars

Pillar I

Entropy

Shannon entropy H(X) = −Σ pᵢ log₂ pᵢ measures the average uncertainty (or information content) of a random variable. It is the fundamental lower bound on lossless compression: no code can compress below H bits per symbol on average. Joint, conditional, and cross-entropy extend the concept to dependent variables and model divergence.

Pillar II

Channel

A communication channel maps inputs to outputs through a conditional probability distribution p(y|x). Channel capacity C = max_{p(x)} I(X;Y) is Shannon's noisy-channel theorem: reliable communication is possible at any rate R < C, and impossible for R > C — a boundary independent of the specific encoding scheme.

Pillar III

Compression

Source coding theorems establish optimal lossless compression at rate H(X) (Shannon) and lossy compression at rate R(D) — the rate-distortion function — for a given fidelity D. Kolmogorov complexity K(x) provides an algorithmic, distribution-free complement: the length of the shortest program generating string x.

Core Concepts

Mutual Information

I(X;Y) = H(X) − H(X|Y): the reduction in uncertainty about X given knowledge of Y. The symmetric measure of statistical dependence between two variables; zero iff X ⊥ Y.

KL Divergence

D_KL(P‖Q) = Σ pᵢ log(pᵢ/qᵢ): the asymmetric "distance" from distribution Q to P. Foundational in Bayesian inference, variational methods, and modern machine learning.

Noisy-Channel Theorem

Shannon's fundamental theorem: for any channel with capacity C and rate R < C, there exist codes achieving arbitrarily low error probability. Proves reliable communication is always achievable in principle.

Rate-Distortion Theory

For lossy compression, the rate-distortion function R(D) gives the minimum bits per source symbol needed to reconstruct within distortion D. Achievable iff R ≥ R(D).

Data Processing Inequality

If X → Y → Z is a Markov chain, then I(X;Z) ≤ I(X;Y): post-processing can never increase mutual information. Establishes fundamental limits on inference pipelines.

Algorithmic Complexity

Kolmogorov complexity K(x) is the length of the shortest program producing x. Incomputable in general but gives a distribution-free notion of randomness: x is random iff K(x) ≈ |x|.

Key Equations

// Shannon's Foundational Formalisms
H(X) = −Σᵢ pᵢ log₂ pᵢ Shannon entropy: the average number of bits needed to encode one outcome of X. Maximized by the uniform distribution; zero for a deterministic variable.
I(X;Y) = H(X) − H(X|Y) Mutual information: how much knowing Y reduces uncertainty about X. Equals H(X) + H(Y) − H(X,Y); symmetric in X and Y.
C = max_{p(x)} I(X;Y) Channel capacity: supremum of mutual information over all input distributions. For an AWGN channel: C = B log₂(1 + SNR) — the Shannon-Hartley theorem.
D_KL(P‖Q) = Σ pᵢ log(pᵢ / qᵢ) Kullback–Leibler divergence: expected log-likelihood ratio under P. Non-negative (Gibbs' inequality), zero iff P = Q; not a metric (asymmetric).
L* ≥ H(X) / log₂ D Source coding lower bound: the expected length L* of any uniquely decodable D-ary code cannot fall below H(X)/log₂D. Huffman codes achieve L* < H(X)/log₂D + 1.

Cross-Module Connections

  • Thermodynamics — Shannon entropy is mathematically identical to Boltzmann-Gibbs entropy S = −k_B Σ pᵢ ln pᵢ; Landauer's principle links information erasure to heat dissipation (k_BT ln2 per bit).
  • Quantum Mechanics — Von Neumann entropy S(ρ) = −Tr(ρ ln ρ) generalizes Shannon entropy to quantum states; entanglement entropy and quantum channel capacity form quantum information theory.
  • Evolutionary Biology — The genetic code is a near-optimal error-correcting code; mutual information between codon and amino acid positions quantifies redundancy and conservation.
  • Chaos Theory — Kolmogorov-Sinai (KS) entropy links topological entropy of a chaotic dynamical system to the Shannon information generation rate; positive KS entropy defines chaos.
  • General Relativity — Bekenstein-Hawking black hole entropy S = kA/4l²_P is the maximum information storable in a region (holographic bound); the holographic principle maps bulk physics to boundary information.
