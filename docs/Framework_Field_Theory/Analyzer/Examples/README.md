## Purpose

This folder contains **worked examples** demonstrating how to use the FFT Analyzer suite across real frameworks, systems, and conceptual models.

Each example includes:

- a declared framework
- operator pattern
- dimensional envelope
- regime state
- coherence profile
- drift vectors
- a final **Framework Field Signature**

These examples serve as:

- teaching tools
- reference patterns
- templates for new analyses
- validation cases for analyzers
