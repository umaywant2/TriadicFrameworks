# **2. The Five Rhythm Classes**

All dimensional rhythms fall into one of five classes:

1. **Oscillatory Rhythms** — back‑and‑forth movement  
2. **Iterative Rhythms** — repeated cycles with variation  
3. **Transitional Rhythms** — phase‑shift patterns  
4. **Coherence Rhythms** — paradox‑integration cycles  
5. **Meta‑Rhythms** — cross‑dimensional synchronization  

These classes appear differently at each dimensional layer.

- two regimes

```
State A ↔ State B ↔ State A ↔ State B
```

3D (transition) → 4D (context) → 5D (rhythm)

# **10. Rhythm Drift Patterns**  
### *How rhythms evolve over time*

Rhythms drift in three ways:

1. **Amplitude Drift** — rhythm becomes stronger or weaker  
2. **Frequency Drift** — rhythm becomes faster or slower  
3. **Dimensional Drift** — rhythm moves to a higher or lower layer  

**Canonical Drift Pattern:**

```
Low‑D Rhythm → Mid‑D Rhythm → High‑D Rhythm
```
