# **3. The Dimensional Learning Spiral**  
### *The core learning cycle of FFT*

The Dimensional Learning Spiral is:

```
Expand → Explore → Compress → Reframe → Expand
```

### **Expand**  
Introduce a higher‑dimensional concept.

### **Explore**  
Let students manipulate, test, and play with it.

### **Compress**  
Reduce it to a simpler representation.

### **Reframe**  
Rebuild understanding from the compressed form.

### **Expand**  
Return to the higher dimension with new coherence.

This spiral is used in every lesson.
