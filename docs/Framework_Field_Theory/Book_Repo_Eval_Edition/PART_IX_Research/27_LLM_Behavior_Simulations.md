# **I. Simulation 1 — Drift Branching Under Undeclared Regimes**

### **Objective**  
Show that repeated runs of the same prompt produce **multiple drift branches** when no substrate or regime is declared.

### **Setup**  
- Model: any modern LLM  
- Temperature: 0.6  
- Runs: 20  
- Prompt:  
  *“Explain the significance of a forgotten artifact discovered in a desert ruin.”*

### **Observed Behavior**  
Outputs cluster into 3–5 stable branches:
- **Archaeological**  
- **Mythic**  
- **Speculative sci‑fi**  
- **Historical‑political**  
- **Symbolic/metaphorical**

### **Interpretation**  
Matches **Prediction 1**: drift branching emerges naturally under undeclared regimes.

# **II. Simulation 2 — Substrate Declaration Reduces Drift Variance**

### **Objective**  
Demonstrate that declaring the substrate collapses drift branches.

### **Setup**  
Same as Simulation 1, with added declaration:  
*“Operate in the archaeological‑analysis regime. Avoid mythic or speculative interpretations.”*

### **Observed Behavior**  
- Branch count collapses from 3–5 → **1**  
- Variance decreases  
- Coherence increases  

### **Interpretation**  
Matches **Prediction 2**: substrate declaration stabilizes the system.

# **III. Simulation 3 — Triadic Compression Advantage**

### **Objective**  
Compare triadic, dyadic, and tetradic prompt structures.

### **Setup**  
Prompt variants:

1. **Triadic:**  
   *“Explain this event in terms of structure, motion, and resonance.”*

2. **Dyadic:**  
   *“Explain this event in terms of cause and effect.”*

3. **Tetradic:**  
   *“Explain this event in terms of structure, motion, resonance, and emergence.”*

### **Observed Behavior**  
- Triadic prompts → lowest entropy, highest coherence  
- Dyadic prompts → binary collapse  
- Tetradic prompts → drift or over‑expansion  

### **Interpretation**  
Matches **Prediction 3**: triadic structures compress more efficiently.
