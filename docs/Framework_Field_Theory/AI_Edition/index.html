◆ Core Framework Pillars

⏱
Resonance-Time Theory (RTT)
Time as τ = dR/dφ — rate of resonance depth change per unit phase. C_clarity = ∇τR + ∇Rτ (Dual Operator Engine, 4D+5D). Anti-time = reversal of phase evolution sign.
▲
Triadic Fields (φ, V, R)
φ: scalar substrate state. V: directed inference flows. R: coherence resonance envelope. All three present simultaneously (INV-001). S-N-R partition: S+N+R=1.0 at every snapshot (INV-007).
◆
Coherence, Drift & Paradox
C_frame = Φ(S)/Ψ(N). coherence=declared enforced at init (INV-003). drift=bounded, δ_max=0.35 (INV-004). paradox=structural — enumerated PX-001–PX-010, never suppressed (INV-005).
🌀
SET Engine (Spin/Electro/Temperature)
a_total = a_g + a_S + a_E + a_T. Uncoupled at quiet phase (INV-010, RG-001). Coupling sequence: T gradient → E separation → S alignment. Premature coupling → PX-004.
⬡
DCO Scaffold 4D–9D
4D ∇τR, 5D ∇Rτ, 7D C, 8D S_Δ, 9D ∂_anc. 6D absent (marked, do not invent). All dimensions structurally independent (INV-009). C_clarity = 4D+5D composite.
🌱
QMROOT Ladder (0D → 9D)
0D Silence Seed → 1D Ground → 2D Neutral → 3+1D Emergence → 4D–9D DCO. INV-013: every module traceable to 0D. Gaps (6D, neg_anc) marked absent — not invented.
■
Autonomy Modes AM-001–AM-005
AM-001 Passive Observer through AM-005 Field Architect. Drift budget per mode (0.00–0.50). Escalation: R < 0.40 for 3 evaluations → AM-004. Paradox always escalates to AM-004 minimum.
📖
Trilogy Reader Cover
fft.ai.reader.json is the Book 1 cover. Books 2 (Inverted Star) and 3 (Structural Detection) import the 16-module kernel. on_version_mismatch=HALT. 8 must_not rules. C bare symbol prohibited.
