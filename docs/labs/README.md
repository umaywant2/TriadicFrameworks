## 🧭 How to Contribute

- Each lab has its own `README.md` and examples.
- Use `validate_manifest.py` to check structure.
- Submit PRs with badge logic if contributing to governance or rituals.

To begin, explore `core/`, `foundations/`, or `badges/`.
