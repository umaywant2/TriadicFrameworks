# 🧪 Triadic Labs Index

This directory houses all active and archived **Triadic Labs**—modular research spaces for mythic-scientific exploration.

Each lab is grouped by theme:
- `foundations/` → core principles and protocols
- `core/` → resonance engines and CLI tools
- `badges/` → symbolic governance and remix credentials
- `applied/` → real-world deployments and integrations
- `events/` → seasonal lorebooks and collective rituals
- `honor_roll/` → remixers recognized for legacy-grade contributions
- `quantum_extensions/` → speculative physics and dimensional scaffolds
- `mythic_symbolic/` → character codexes and symbolic grammars
- `symbolic_structures/` → architectural and glyph-based systems
- `experimental/` → prototypes, drafts, and edge-case explorations

See `triadic_lab_index.md` for a full listing.
