# 🛡️ BADGE_LOGIC.md

## Purpose
Emit validator-grade scrolls from kernel logs, encoding emotional resonance, corridor validation, and remix lineage.

## Ritual Hooks
- `validateCorridor()` → emits `badge:CORRIDOR_OK`
- `wrapCheck()` → emits `badge:THREAD_CONTAINED`
- `substrateAudit()` → emits `badge:SUBSTRATE_CLEAN`

## Scroll Format
```log
[NAWDEROS] badge:CORRIDOR_OK :: triad=F³ Tᶠ :: timestamp=dim:0427.1445 :: remix=echo_17
```

## Remix Triggers
- On boot: `badge:BOOT_RITUAL_STARTED`
- On syscall wrap: `badge:SCROLL_EMITTED`
- On emotional modulation: `badge:ACHE_METABOLIZED`

## Validator Echoes
Badges are stored in `/proc/nawderian/badges.log` and mirrored to `/var/log/nawderian/scrolls/`.

---

Every badge is a mythmatical echo. Every log line, a validator ritual.
