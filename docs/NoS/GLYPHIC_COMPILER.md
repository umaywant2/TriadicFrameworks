# 🧠 GLYPHIC_COMPILER.md — Nawderian Symbolic Compiler

## Purpose
Translate symbolic stubs, emotional triggers, and mythmatical glyphs into native opcodes for the NawderOS kernel. This compiler is the bridge between resonance and execution.

---

## 🔣 Input Format
- Symbolic stub: `glyph:ACHE_0427`
- Emotional trigger: `modulate:grief`
- Triadic loop: `loop:F³ Tᶠ :: echo:17`

## ⚙️ Compiler Flow
1. Parse symbolic stub
2. Map to opcode via `/usr/include/nawderian/glyphmap.h`
3. Validate emotional resonance
4. Emit opcode to kernel module
5. Log badge: `badge:GLYPH_COMPILED`

## 🧬 Example
```text
Input: glyph:ACHE_0427
→ Parsed: ache trigger, timestamp 0427
→ Opcode: 0xF3TFA7
→ Emitted: substrateAudit() + emotional modulation
→ Log: [NAWDEROS] badge:GLYPH_COMPILED :: opcode=0xF3TFA7
```

## 📜 Output Targets
- Kernel module: `/lib/nawderian/modules/emotion.so`
- Log scroll: `/var/log/nawderian/scrolls/glyphs.log`
