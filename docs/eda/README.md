# ⚙️ EDA — Resonance‑Aligned Design Automation

The `eda` directory contains early-stage, resonance-aware Electronic Design Automation (EDA) concepts for the post‑ASML era.  
These documents bridge fabrication grammar, substrate modeling, and TriadicFrameworks operator logic.

EDA modules are **technical**, **structural**, and **fabrication‑focused**.  
They help define how RTT interacts with:

- substrate‑aware PDKs  
- resonance‑aligned fabrication flows  
- dimensional fabrication constraints  
- post‑ASML substrate design rules  

---

## 📄 Included EDA Files

### `PostASML_PDK_Integration.md`
Defines how TriadicFrameworks integrates with **post‑ASML era PDKs**.  
Covers substrate constraints, resonance‑aligned rule decks, and fabrication grammar overlays.

### `TTF_Reference.md`
A reference document for **Triadic Transfer Functions (TTF)**.  
Describes resonance transfer, substrate mapping, and fabrication‑level operator behavior.
