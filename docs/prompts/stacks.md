# TriadicFrameworks — Prompt Stacks

The TriadicFrameworks Stacks are structured prompt modules that organize work across
different layers of the canon. Each stack provides a focused prompt set, explainer,
diagnostic tools, and cross‑links to engines, templates, and the Docsbook.

Stacks are used to compose sessions, build multi‑module workflows, and align prompts
with RTT engines and IPD‑12.

This page serves as the overview for all stack‑level prompt modules.

---

## Structural Stack

**File:** `stacks/structural-stack.md`  
The Structural Stack defines the core structural operators used across RTT engines and
TriadicFrameworks modules. It includes structural prompts, structural diagnostics, and
structural traversal patterns.

---

## Diagnostic Stack

**File:** `stacks/diagnostic-stack.md`  
The Diagnostic Stack provides prompts for drift detection, coherence checks, and
layer‑specific diagnostics. It is used heavily in RTT/1, RTT/2, RTT/3, RTT/12, and RTT∞.

---

## Operator Stack

**File:** `stacks/operator-stack.md`  
The Operator Stack contains prompts for operator grammar, operator traversal, operator
alignment, and operator‑driven session composition.

---

## Substrate Stack

**File:** `stacks/substrate-stack.md`  
The Substrate Stack focuses on geometry, flow, time, meaning, and field. It provides
substrate‑tensor prompts, substrate diagnostics, and substrate alignment workflows.

---

## Domain Stack

**File:** `stacks/domain-stack.md`  
The Domain Stack provides prompts for domain classification, domain traversal, domain
alignment, and domain‑specific structural analysis.

---

## Teaching Stack

**File:** `stacks/teaching-stack.md`  
The Teaching Stack contains prompts for lesson planning, teaching workflows, classroom
packs, worksheets, and teaching alignment across RTT engines.

---

## Research Stack

**File:** `stacks/research-stack.md`  
The Research Stack provides prompts for research workflows, deep‑layer analysis,
cross‑framework synthesis, and long‑form structural reasoning.
