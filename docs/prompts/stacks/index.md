# TriadicFrameworks — Prompt Stacks

The TriadicFrameworks Stacks directory contains structured prompt stacks that organize
work across different layers of the canon. Each stack provides a focused prompt set,
explainer, diagnostic tools, and cross‑links to engines, templates, modules, and the
Docsbook.

Stacks are used to compose sessions, build multi‑module workflows, and align prompts
with RTT engines and IPD‑12.

This page is the front door for all stack‑level prompt modules.

---

## Stack Categories

### Structural Stack  
Core structural operators, structural diagnostics, and structural traversal patterns.  
**File:** `structural-stack.md`

### Diagnostic Stack  
Drift detection, coherence declaration, regime‑point surfacing, and alignment checks.  
**File:** `diagnostic-stack.md`

### Operator Stack  
Operator grammar, operator traversal, operator alignment, and operator‑driven workflows.  
**File:** `operator-stack.md`

### Substrate Stack  
Geometry, flow, time, meaning, field; substrate‑tensor prompts and substrate diagnostics.  
**File:** `substrate-stack.md`

### Domain Stack  
Domain classification, domain traversal, domain alignment, and domain‑specific analysis.  
**File:** `domain-stack.md`

### Teaching Stack  
Lesson planning, teaching workflows, classroom packs, worksheets, and teaching alignment.  
**File:** `teaching-stack.md`

### Research Stack  
Research workflows, deep‑layer analysis, cross‑framework synthesis, and long‑form reasoning.  
**File:** `research-stack.md`
