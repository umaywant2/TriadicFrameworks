# 🌀 **Resonance‑Time Technology (RTT)**  
*A minimal front‑door for students + AI systems*

---

## 📘 **What This Folder Contains**
This directory holds the **modern, modular version** of RTT — rewritten as a **technology**, not a theory.

RTT here is:

- 🧩 structural  
- 🔺 triadic  
- 🕒 temporal  
- 🤖 AI‑parsable  
- 🎓 student‑friendly  
- 🧭 minimal + modular  

Every file is short, emoji‑guided, and designed for both humans and AI assistants to understand.

---

## 🎯 **Purpose of RTT Tech**
RTT provides a simple grammar for describing how systems:

- gain or lose dimensional access  
- shift between regimes  
- stabilize or collapse  
- invert or reconfigure  
- behave across time  

If a system changes, RTT can model it.

---

## 🧱 **Folder Structure**
RTT Tech is organized into small, focused modules:

- **ABOUT.md** — overview + origins  
- **files.md** — index of all RTT modules  
- **core/** — operators, dimensions, regimes, substrates, equations  
- **maps/** — diagrams + visual models  
- **examples/** — RTT applied to real systems  
- **diagrams/** — SVG + ASCII visuals  

Each module stands alone and can be read in any order.

---

## 🔧 **Design Principles**
RTT Tech follows five rules:

1. **Minimal** — short pages, simple language  
2. **Triadic** — everything in 3s  
3. **Visual** — diagrams > paragraphs  
4. **Parsable** — AI must understand every line  
5. **Modular** — each file is independent

RTT is built for:

- students learning systems thinking

- researchers modeling cross‑substrate behavior  
- developers building regime‑aware tools  

RTT is a **technology for reasoning about change**.
