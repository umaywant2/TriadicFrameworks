# 🧩 **What Is a “Customer Core Wrapper”?**
###### By Nawder Loswin 1/14/2026 © www.TriadicFrameworks.org

A **customer core wrapper** is a thin, branded, configurable layer that sits *around* a canonical RTT cor 
It provides:

- **identity** (branding, naming, visuals)  
- **integration** (APIs, connectors, templates)  
- **context** (industry framing, examples, use cases)  
- **permissions** (what the customer can modify or resell)  
- **safety** (so the raw core is never exposed or altered)  

Think of it like a beautifully designed case around a precision instrument.

The instrument stays the sam 
The case makes it sellable, ownable, and safe.

---

# 🛡️ **Why We Never Sell “Naked Cores”**  
Selling a raw RTT core would:

- confuse customers  
- risk misuse  
- dilute your IP  
- make versioning impossible  
- destroy lineage and authorship  
- prevent resellers from adding value  

A wrapper solves all of this.

### High‑level architecture

**Service name:** `wrapper-factory-orchestrator`

**Core components:**

- **Flow Manager** — state machine for wrapper lifecycles  
- **Profile Resolver** — resolves industry + customer into capabilities  
- **Branding Coordinator** — calls branding engine and validates identity  
- **Integration Planner** — selects and validates integration modules  
- **Config Assembler** — builds configuration layer from modules + features  
- **License Binder** — attaches correct license to wrapper  
- **Core Guardian** — enforces core version, immutability, checksum  
- **Artifact Builder** — composes final package (wrapper + docs + metadata)  
- **Lineage Logger** — records every step for audit and traceability  

---

### Wrapper lifecycle (internal state machine)

States:

`INIT`  
`PROFILE_RESOLVED`  
`BRANDING_READY`  
`INTEGRATIONS_PLANNED`  
`CONFIG_COMPOSED`  
`LICENSE_BOUND`  
`CORE_VERIFIED`  
`ARTIFACT_BUILT`  
`COMPLETED`  
10. `FAILED`  

Transitions are **only** allowed forward; any failure moves to `FAILED` with a full trace.

---

### Orchestration flow (step‑by‑step)

#### Step 1 — Initialize wrapper request
- Input: `industryId`, `customerType`, optional `branding`, `modules`, `features`
- Orchestrator creates a `wrapperRequestId`
- State: `INIT → PROFILE_RESOLVED`

#### Step 2 — Resolve profiles
- Calls internal equivalents of `/industries` and `/customers`
- Validates that combination is supported
- Attaches industry + customer capabilities
- State: `PROFILE_RESOLVED`

#### Step 3 — Branding coordination
- If branding provided: validate and normalize  
- If not: generate default name/tagline/palette from templates  
- Calls Branding Engine for preview + identity bundle  
- State: `BRANDING_READY`

#### Step 4 — Integration planning
- Uses industry + customer profile to propose default modules  
- Applies partner overrides (if allowed)  
- Validates required modules are present  
- State: `INTEGRATIONS_PLANNED`

#### Step 5 — Configuration assembly
- Calls Config Engine to compose:
  - modules  
  - feature toggles  
  - dashboards  
  - presets  
- Returns `configId`
- State: `CONFIG_COMPOSED`

#### Step 6 — License binding
- Calls Licensing Engine with:
  - customer type  
  - resale/white‑label flags  
- Returns `licenseId`
- State: `LICENSE_BOUND`

#### Step 7 — Core verification
- Calls Core Manager:
  - fetch current core version  
  - verify checksum  
  - ensure compatibility with industry/customer profile  
- Locks core version into wrapper metadata
- State: `CORE_VERIFIED`

#### Step 8 — Artifact build
- Calls Artifact Builder with:
  - branding bundle  
  - config bundle  
  - license bundle  
  - core reference  
- Produces:
  - wrapper package URL  
  - docs URL  
  - update channel metadata  
- State: `ARTIFACT_BUILT → COMPLETED`

- `POST /wrappers` → orchestrator starts lifecycle  
- `POST /generate` → orchestrator runs remaining steps if needed  
- `GET /wrappers/{id}` → current state + artifact links  

Internally, the orchestrator is the only thing allowed to:

- bind core + wrapper  
- finalize artifacts  
- mark a wrapper as canonical

# 🧭 **wrapper_factory/orchestrator.py**

```python
# orchestrator.py
from .profiles import INDUSTRIES, CUSTOMERS
from .branding import BrandingEngine
from .integrations import IntegrationPlanner
from .config import ConfigAssembler
from .licensing import LicenseEngine
from .core_guardian import CoreGuardian
from .artifact_builder import ArtifactBuilder
from .lineage import LineageLogger


class WrapperOrchestrator:
    def __init__(self):
        self.branding = BrandingEngine()
        self.integrations = IntegrationPlanner()
        self.config = ConfigAssembler()
        self.licensing = LicenseEngine()
        self.core = CoreGuardian()
        self.builder = ArtifactBuilder()

    def generate_wrapper(self, industry, customer, name, tagline):
        log = LineageLogger()

        log.log("Resolving profiles")
        industry_profile = INDUSTRIES[industry]
        customer_profile = CUSTOMERS[customer]

        log.log("Generating branding")
        branding = self.branding.generate(name, tagline)

        log.log("Planning integrations")
        integrations = self.integrations.plan(industry_profile, customer_profile)

        log.log("Assembling configuration")
        config = self.config.assemble(
            modules=integrations["modules"],
            features=customer_profile.features
        )

        log.log("Binding license")
        license_data = self.licensing.generate(customer)

        log.log("Verifying core")
        core_info = self.core.verify()

        wrapper = {
            "wrapperId": f"wrap-{hash(name) % 99999}",
            "branding": branding,
            "integrations": integrations,
            "config": config,
            "license": license_data,
            "core": core_info,
            "lineage": log.export()
        }

        log.log("Building artifact")
        artifact = self.builder.build(wrapper)

        wrapper["artifact"] = artifact
        wrapper["lineage"] = log.export()

        return wrapper
```

def main():

    parser.add_argument("--customer", required=True, help="Customer type")
    parser.add_argument("--name", required=True, help="Wrapper product name")
    parser.add_argument("--tagline", required=True, help="Wrapper tagline")

    args = parser.parse_args()

    orchestrator = WrapperOrchestrator()
    wrapper = orchestrator.generate_wrapper(
        industry=args.industry,
        customer=args.customer,
        name=args.name,
        tagline=args.tagline
    )

    print("\n=== Wrapper Generated ===")
    print(f"Wrapper ID: {wrapper['wrapperId']}")
    print(f"Artifact URL: {wrapper['artifact']['artifactUrl']}")
    print(f"Documentation: {wrapper['artifact']['documentationUrl']}")
    print("\nLineage:")
    for step in wrapper["lineage"]:
        print(f" - {step}")


if __name__ == "__main__":
    main()
