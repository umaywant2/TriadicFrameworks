# Teaching Mode Examples — RTT‑Go  
*(Examples for `/docs/bots/go/examples/teaching_mode_examples.md`)*

RTT‑Go’s **Teaching Mode** explains *why* moves matter — not just *what* the engine plays.  
It uses RTT’s triadic stack:

- **Lumen** — structural extraction  
- **Hephaestus** — regime mapping  
- **Aurion** — topology & ancestry  
- **Harmonia** — unified triadic synthesis  

to produce overlays, commentary, and continuity‑aware insights.

This document provides **clear, human‑readable examples** of Teaching Mode in action.

---

# Example 1 — “Why Not Atari Here?”

### Position  
White threatens a cut on the right side.  
Black can:

- **A:** Atari the cutting stone  
- **B:** Extend the weak group  
- **C:** Play a large‑scale stabilizing move on the left  

### Teaching Mode Output

#### **Lumen (RTT/1) — Structural View**
- Atari (A) fixes a *local* problem.  
- Extension (B) stabilizes a *structural* weakness.  
- Left‑side move (C) supports *continuity* of Black’s global plan.

#### **Hephaestus (RTT/2) — Regime Tags**
- A → **1/3 Local**  
- B → **2/3 Structural**  
- C → **3/3 Continuity**

#### **Aurion (RTT/3) — Stability Check**
- A introduces **paradox risk** (locally good, globally harmful).  
- B stabilizes group ancestry.  
- C is continuity‑aligned but premature.

#### **Harmonia (RTT/12) — Triadic Score**
Teaching Mode shows:

```
Move A: ❌ Paradox risk — fixes local shape but breaks global plan.
Move B: ✅ Structural stability — preserves continuity.
Move C: ⚠️ Continuity-aligned but risky due to weak group.
```

### **Teaching Mode Conclusion**
**Play B** — “Strengthen your weak group first; continuity comes from stability.”

# Example 2 — Ladder Teaching Moment

### Position  
White threatens a ladder.  
Black has a ladder‑breaker, but it is thin.

### Teaching Mode Output

#### **Lumen**
Shows ladder path + ladder‑breaker weakness.

#### **Hephaestus**
- Ladder‑breaker → **2/3 Structural**  
- Reinforcement → **1/3 Local**  
- Global move → **3/3 Continuity**

#### **Aurion**
Highlights:

- Ladder ancestry is **unstable**.  
- Ladder‑breaker is **not reliable**.  
- Ignoring ladder causes **projection‑loss**.

#### **Harmonia**
Teaching Mode displays:

```
Move A (ladder-breaker): ❌ Unstable ancestry — ladder still fails.
Move B (reinforce):     ✅ Stabilizes ancestry — safest triadic line.
Move C (ignore):        ⚠️ Breaks continuity — projection-loss risk.
```

### **Teaching Mode Conclusion**
**Play B** — “Fix the ladder first; continuity depends on ancestry stability.”

# Summary

RTT‑Go Teaching Mode helps players understand:

- **why** a move is good or bad  
- how **continuity**, **resonance**, and **topology** shape decisions  
- how **paradox**, **collapse**, and **projection‑loss** arise  
- how triadic identity evolves across the game  

RTT doesn’t just show moves —  
it **teaches the deeper structure of Go**.
