# Analysis Mode Examples — RTT‑Go  
*(Examples for `/docs/bots/go/examples/analysis_mode_examples.md`)*

RTT‑Go’s **Analysis Mode** evaluates completed games or ongoing positions using the full triadic engine stack:

- **Regime Engine**  
- **Resonance Engine**  
- **Topology Engine**  
- **Continuity Engine**  
- **Risk Engine**  
- **Scoring Engine**

It does not choose moves — it **explains** the triadic identity of the position, highlights paradox/collapse risks, and reveals continuity arcs, ancestry, drift, and resonance fields.

This document provides clear, structured examples of Analysis Mode in action.

---

# Example 1 — Identifying a Paradox Move

### Position  
White has just played a forcing move on the right side that looks locally strong.

### Analysis Mode Output

#### **Regime Engine**
- Move is **1/3 local**  
- Structural regime weakened  
- Continuity regime disrupted

#### **Resonance Engine**
- Pressure spike detected  
- Influence gradient reversed  
- Local gain causes global imbalance

#### **Topology Engine**
- Cut point introduced  
- Connectivity weakened  
- Ladder ancestry destabilized

#### **Continuity Engine**
- Territorial arc contradiction  
- Continuity drift reversal  
- Identity inversion risk: **medium**

#### **Risk Engine**
- **Paradox detected**  
- Collapse precursor present  
- Projection‑loss risk: **high**

#### **Scoring Engine**
- Local score ↑  
- Structural score ↓↓  
- Continuity score ↓  
- Final triadic score: **low**

### **Analysis Mode Conclusion**
“White’s move gains locally but breaks global continuity. This is a paradox move — strong in isolation, weak in identity.”
