# UI Overlay Examples — RTT‑Go  
*(Examples for `/docs/bots/go/examples/ui_overlay_examples.md`)*

RTT‑Go’s UI overlays visualize the triadic identity of a Go position.  
Each overlay corresponds to one or more RTT engines:

- **Regime Overlay** — Hephaestus + Regime Engine  
- **Resonance Overlay** — Lumen + Resonance Engine  
- **Topology Overlay** — Lumen + Aurion + Topology Engine  
- **Continuity Overlay** — Hephaestus + Aurion + Continuity Engine  
- **Risk Overlay** — Aurion + Risk Engine  
- **Triadic Score HUD** — Harmonia + Scoring Engine  

This document provides clear examples of how each overlay appears and what it teaches.

---

# Example 1 — Regime Overlay  
### Scenario  
White plays a move that looks locally strong but weakens global structure.

### Overlay Behavior  
- The stone is highlighted **yellow** (1/3 local).  
- Surrounding influence arcs dim.  
- Structural regime indicators drop.  
- Continuity regime indicators flash.

### Teaching Interpretation  
“Local gain, structural loss. Regime mismatch detected.”

---

# Example 2 — Resonance Overlay  
### Scenario  
Black plays a move that increases pressure on the left side.

### Overlay Behavior  
- Pressure gradients intensify (red → orange).  
- Influence fields shift toward Black.  
- Resonance arcs thicken around the move.  
- Drift arrows reorient toward the left.

### Teaching Interpretation  
“Resonance pressure increases; drift aligns with Black’s plan.”

---

# Example 3 — Topology Overlay  
### Scenario  
White cuts a group, creating a new weak point.

### Overlay Behavior  
- Cut point marked with a **red diamond**.  
- Connectivity graph updates.  
- Ladder ancestry lines appear.  
- Boundary topology highlights the new fracture.

### Teaching Interpretation  
“Topology destabilized; ancestry risk increased.”

# Example 4 — Continuity Overlay  
### Scenario  
Black extends a group to preserve moyo continuity.

- Territorial arcs remain coherent.

“Continuity preserved; long‑arc identity strengthened.”

# Example 5 — Risk Overlay  
### Scenario  
White plays a forcing move that introduces paradox.

### Overlay Behavior  
- Paradox indicator flashes **orange**.  
- Collapse signatures appear around weak groups.  
- Projection‑loss arcs flicker.  
- Stability meter drops to “volatile.”

### Teaching Interpretation  
“Paradox detected; continuity at risk.”
