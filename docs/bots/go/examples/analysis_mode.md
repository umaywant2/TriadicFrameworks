# Analysis Mode — RTT‑Go  
*(Long‑Arc Structural & Continuity Commentary)*

Analysis Mode is RTT‑Go’s **post‑game triadic commentator**.  
Instead of selecting moves, RTT analyzes a completed (or ongoing) game and reveals the **structural**, **topological**, and **continuity‑arc** dynamics that shaped the position.

Analysis Mode is ideal for:

- reviewing human games  
- studying long‑arc strategy  
- diagnosing collapse events  
- understanding paradoxes  
- exploring continuity arcs and ancestry  
- teaching advanced Go concepts through RTT structure  

RTT does not play moves in analysis mode — it **explains** them.

---

## Purpose

Analysis Mode provides:

- triadic regime classification per move  
- resonance field evolution  
- topology graph changes  
- continuity‑arc evolution  
- ancestry alignment and breaks  
- paradox and projection‑loss detection  
- collapse‑signature identification  
- long‑arc strategic commentary  

It transforms a game record into a **triadic narrative**.

---

## Analysis Mode vs Teaching Mode

| Feature | Teaching Mode | Analysis Mode |

Teaching Mode explains *candidate moves*.
