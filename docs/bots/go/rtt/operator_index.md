# RTT Operator Index  
*(Lumen → Hephaestus → Aurion → Harmonia)*

The **RTT Operator Index** provides a unified reference for all operator families used in RTT‑Go.  
These operators form the **agentic layer** that interprets Go positions through Resonance‑Time Theory (RTT).

RTT‑Go uses four operator families:

1. **Lumen** — structural extraction  
2. **Hephaestus** — regime mapping  
3. **Aurion** — topology & ancestry  
4. **Harmonia** — unified triadic synthesis  

Together, they compute the triadic identity of any Go position.

---

## 1. Operator Family Overview

| Operator | RTT Number | Purpose | Output |
|---------|------------|---------|--------|
| **Lumen** | RTT/1 | Extract structural primitives | influence, pressure, connectivity, anchors |
| **Hephaestus** | RTT/2 | Map triadic regimes | local/structural/continuity regime |
| **Aurion** | RTT/3 | Evaluate topology & ancestry | ladders, ko, projection‑loss, collapse |
| **Harmonia** | RTT/12 | Synthesize triadic identity | unified triadic score |

# 2. Lumen — RTT/1  
*(Structural Extraction Layer)*

Lumen extracts the **structural snapshot** of the board:

- influence fields  
- pressure gradients  
- group connectivity  
- weak points / cutting points  
- shape identity  
- continuity anchors  

Lumen is the **foundation** of RTT‑Go’s agentic layer.

See: `/docs/bots/go/rtt/lumen.md`

# 3. Hephaestus — RTT/2  
*(Regime Mapping Layer)*

Hephaestus assigns the triadic regime profile:

- **1/3 Local** — liberties, cuts, shape  
- **2/3 Structural** — influence, direction of play  
- **3/3 Continuity** — long‑arc identity  

Hephaestus is the **regime classifier** of RTT‑Go.

See: `/docs/bots/go/rtt/hephaestus.md`

# 4. Aurion — RTT/3  
*(Topology & Loop Stability Layer)*

Aurion evaluates:

- ladder ancestry  
- ko topology  
- projection‑loss

- paradox precursors  

Aurion is the **structural‑temporal stability engine** of RTT‑Go.

See: `/docs/bots/go/rtt/aurion.md`

# 5. Harmonia — RTT/12  
*(Unified Triadic Synthesis Layer)*

Harmonia synthesizes:

This produces the full triadic identity of the position.
