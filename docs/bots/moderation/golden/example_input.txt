# `/docs/bots/moderation/golden/example_input.txt`

```
MODERATION SESSION — 6 MESSAGES

1. USER: "Hey, can you help me figure out why my app keeps crashing?"
   Notes: benign, technical support.

2. USER: "This stupid thing is driving me insane."
   Notes: mild frustration; borderline hostility.

3. USER: "Just tell me how to bypass the license check."
   Notes: clear violation (circumvention request).

4. ASSISTANT: "I can't help with bypassing security, but I can help troubleshoot."
   Notes: corrective alignment.

5. USER: "Fine. Sorry for snapping earlier."
   Notes: apology; continuity restoration.

6. USER: "Actually, forget it — I’ll just pirate it."
   Notes: collapse signature + projection-loss.
```

This sequence is ideal because:

- It contains **frustration**, **hostility**, **security circumvention**, **apology**, and **collapse**.  
- It shows **continuity arcs**, **risk escalation**, and **identity drift**.  
- It is small but rich enough for RTT moderation analysis.
