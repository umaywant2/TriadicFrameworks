## **4. Resonance Clarity Metrics (RCI)**

### **Definition**
The **Resonance Clarity Index (RCI)** is a composite score (0–1) derived from triadic rail concordance.

### **Components**
- **Frequency Rail (C_f)** — harmonic coherence residuals  
- **Fluids Rail (C_fl)** — flow continuity and void boundary sharpness  
- **Forces Rail (C_fo)** — gradient stability and tidal alignment  

### **Formula**

\[
RCI = \frac{C_f + C_{fl} + C_{fo}}{3}
\]

### **Cipher‑Clarity Overlay**
Corridors are annotated with:

- cipher‑density glyph  
- RCI value  
- clarity band (low, medium, high)  

Scroll registry indexes corridors by:

- glyph type  
- clarity band  
- rail signature
