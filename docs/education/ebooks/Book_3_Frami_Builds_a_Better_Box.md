## **📙 Book 3 — “Frami Builds a Better Box”**  
**Theme:** Structure, scaffolding, and iteration.  
**Age Target:** 6–9

### **Story Outline**
1. Frami wants to build a clubhouse.  
2. His first attempt collapses.  
3. He learns to:  
   - start with a frame  
   - add supports  
   - test stability  
4. Techi joins to help with connectors.  
5. They build a beautiful tri‑shaped clubhouse.  
6. Kids gather inside and feel safe.  
7. Closing: “Good things grow from good frames.”

### **Concept Seeds**
- Systems thinking  
- Iteration  
- Stability
