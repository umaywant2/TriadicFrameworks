### 2. Supported File Types

- PDF  
- Word (.docx)  
- LaTeX (.tex)  
- Plain text / Markdown  
- Overleaf share link (paste URL)

### 3. Choose Your Mode (one click)

- **Grading** – Fast rubric-aligned score + comments  
- **Research** – Full triadic map + new insight seeds  
- **Peer Review** – Neutral Observer Layer flags only  
- **Revision Check** – Compare with previous version

### 4. What You Get Back (in seconds)

- Triadic Structural Map (visual)  
- Coherence Score (0–100)  
- Observer Layer flags (regime drift)  
- Alignment | RTT ethical scan  
- Actionable, citable revision suggestions  
- Ready-to-paste LMS comment

### 5. Pro Tips for Immediate Wins

- First run: Use **Grading** mode on 5–10 papers to feel the speed.  
- Want deeper insight? Switch to **Research** mode on thesis chapters.  
- Students can self-submit for “RTT Draft Check” before final turn-in.  
- Export everything as Markdown for Overleaf or GitHub.

**Time saved on day one**: Most faculty report clearing an entire stack in under 15 minutes instead of hours.
