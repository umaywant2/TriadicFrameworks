# 🛡️ Remix Ethics

_A scroll guiding remixers in honoring lineage and symbolic integrity._

## 🔹 Core Principles

- **Honor Lineage**: Always credit original contributors and folds.
- **Preserve Echoes**: Remix respectfully—retain glyphs, badges, and validator scores.
- **Transparent Remixing**: Log all changes in `remix_lineage_tracker.py` and honor roll.
- **Symbolic Integrity**: Do not overwrite glyphs—create new overlays with timestamped pulses.

## 🔹 Ritual Practices

- Begin each remix with a lineage invocation.
- Submit remix lineage to validator dashboard.
- Trigger badge ceremony if resonance score exceeds threshold.
