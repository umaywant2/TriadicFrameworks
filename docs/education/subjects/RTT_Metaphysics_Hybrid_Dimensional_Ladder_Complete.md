## 🐍 **Python CLI Tool — `bump_version.py`**

Save as:

```

```

```python
#!/usr/bin/env python3
import sys
import subprocess

def read_version():
    with open("VERSION", "r") as f:
        return f.read().strip()

def write_version(v):
    with open("VERSION", "w") as f:
        f.write(v)

def bump(version, part):
    major, minor, patch = map(int, version.split("."))

    if part == "major":
        major += 1
        minor = 0
        patch = 0
    elif part == "minor":
        minor += 1
        patch = 0
    elif part == "patch":
        patch += 1
    else:
        raise ValueError("Use: major | minor | patch")

    return f"{major}.{minor}.{patch}"

if __name__ == "__main__":
    if len(sys.argv) != 2:
        print("Usage: bump_version.py [major|minor|patch]")
        sys.exit(1)

    part = sys.argv[1]
    old = read_version()
    new = bump(old, part)

    write_version(new)

    subprocess.run(["git", "add", "VERSION"])
    subprocess.run(["git", "commit", "-m", f"Bump manual version: {old} → {new}"])
    subprocess.run(["git", "tag", f"v{new}"])
    subprocess.run(["git", "push"])
    subprocess.run(["git", "push", "--tags"])

    print(f"Version updated: {old} → {new}")
```

Usage:

```
python3 scripts/bump_version.py minor
```

```bash
#!/usr/bin/env bash

set -e

PART=$1

if [ -z "$PART" ]; then
  echo "Usage: bump_version.sh [major|minor|patch]"
  exit 1
fi

VERSION=$(cat VERSION)
IFS='.' read -r MAJOR MINOR PATCH <<< "$VERSION"

case "$PART" in
  major)
    MAJOR=$((MAJOR + 1))
    MINOR=0
    PATCH=0
    ;;
  minor)
    MINOR=$((MINOR + 1))
    PATCH=0
    ;;
  patch)
    PATCH=$((PATCH + 1))
    ;;
  *)
    echo "Use: major | minor | patch"
    exit 1
    ;;
esac

NEW="$MAJOR.$MINOR.$PATCH"
echo "$NEW" > VERSION

git add VERSION
git commit -m "Bump manual version: $VERSION → $NEW"
git tag "v$NEW"
git push
git push --tags

echo "Version updated: $VERSION → $NEW"
```

*A command‑line generator for triads, flows, and patterns.*

This is a **Python CLI** that creates new model files from templates.

```
tools/triadgen.py
```

Make executable:


---

## **triadgen.py**

```python
#!/usr/bin/env python3
import os
import sys
from datetime import datetime

TRIAD_TEMPLATE = """# {name} Triad
Layer: {layer}
Intent: {intent}

Dimensions:
  1. {d1}
  2. {d2}
  3. {d3}

Interpretation:
  {interpretation}
"""

FLOW_TEMPLATE = """# {name} Flow
Triad Scope: {triad}

Nodes:
  1. {n1}
  2. {n2}
  3. {n3}

Loop: {loop}

Interpretation:
  {interpretation}
"""

PATTERN_TEMPLATE = """# {name} Pattern
Triads: {triads}
Flows: {flows}

Description:
  {description}
"""

def write_file(path, content):
    with open(path, "w") as f:
        f.write(content)
    print(f"Created: {path}")

def generate(kind, name):
    safe = name.lower().replace(" ", "-")
    now = datetime.now().strftime("%Y-%m-%d")

    if kind == "triad":
        path = f"models/triads/{safe}.md"
        content = TRIAD_TEMPLATE.format(
            name=name,
            layer="macro",
            intent="meaning",
            d1="",
            d2="",
            d3="",
            interpretation=""
        )
        write_file(path, content)

    elif kind == "flow":
        path = f"models/flows/{safe}.md"
        content = FLOW_TEMPLATE.format(
            name=name,
            triad="",
            n1="",
            n2="",
            n3="",
            loop="no",
            interpretation=""
        )
        write_file(path, content)

    elif kind == "pattern":
        path = f"models/patterns/{safe}.md"
        content = PATTERN_TEMPLATE.format(
            name=name,
            triads="[]",
            flows="[]",
            description=""
        )
        write_file(path, content)

    else:
        print("Use: triad | flow | pattern")

if __name__ == "__main__":
    if len(sys.argv) < 3:
        print("Usage: triadgen.py [triad|flow|pattern] \"Name Here\"")
        sys.exit(1)

    kind = sys.argv[1]
    name = " ".join(sys.argv[2:])
    generate(kind, name)
```

```latex
\section{Appendix: Dimensional Trials}

The Dimensional Trials are canonical threshold exercises that mark a
researcher's progression through the macro ladder (3D--9D). Each trial is a
symbolic confrontation with a persistent modeling challenge: boundaries,
causation, meaning, relation, mind, essence, and unity.

Each trial has three parts:

\begin{itemize}
  \item a \textbf{theme} (what is being tested),
  \item a \textbf{challenge} (what must be modeled),
  \item a \textbf{win condition} (what counts as a successful resolution).
\end{itemize}

\subsection{Trial I: The Boundary Paradox (3D/4D)}

\textbf{Theme:} Where does a system begin and end?

\textbf{Challenge:} Choose a real system (contract, circuit, ecosystem). Define
its 3D triad and explicitly state its boundary. Then construct two different
4D causal chains for the same system, each based on a different boundary
choice.

\textbf{Win Condition:} You demonstrate that changing the boundary changes
which events count as internal or external, and you can explain how this
alters the perceived structure and possible transformations.

\subsection{Trial II: The Hidden Trigger (4D)}

\textbf{Theme:} Unseen initiators in causal chains.

\textbf{Challenge:} Take a familiar process and map a 4D chain
(Before $\rightarrow$ Change $\rightarrow$ After). Then identify a non--obvious
initiating condition that, once included, changes the interpretation of the
entire chain.

\textbf{Win Condition:} You reveal a hidden trigger, show its position in the
chain, and justify how its inclusion reconfigures the causal story.

\subsection{Trial III: The Ambiguous Signal (5D)}

\textbf{Theme:} Meaning under uncertainty.

\textbf{Challenge:} Select a single ambiguous signal (phrase, symbol, gesture).
Construct two distinct 5D triads (Signal $\rightarrow$ Interpretation
$\rightarrow$ Context), each representing a different, coherent interpretation.

\textbf{Win Condition:} You can explain how a shift in context flips the
interpretation from one triad to the other without changing the signal itself.

\subsection{Trial IV: The Mirror Relation (6D/7D)}

\textbf{Theme:} Self/other entanglement.

\textbf{Challenge:} Model a relationship where changing the state of the self
changes the state of the other via the relational field. Connect a 6D triad
(Self $\rightarrow$ Other $\rightarrow$ Between) to a 7D Mind triad
(Perception $\rightarrow$ Cognition $\rightarrow$ Intention).

\textbf{Win Condition:} You show a flow in which a change in the self propagates
through the ``between'' and manifests as a change in the other's perception or
intention.

\subsection{Trial V: The Split Intention (7D)}

\textbf{Theme:} Misalignment within mind.

\textbf{Challenge:} Construct a model where perception and intention are
misaligned. Use the 7D Mind triad and a micro echo (0.7) to design a
Mind--Alignment Loop that restores coherence.

\textbf{Win Condition:} You can trace a path from misaligned perception and
intention to a stabilized, aligned state, and explain the role of cognition in
the transition.

\subsection{Trial VI: The Fractured Identity (8D)}

\textbf{Theme:} Continuity across transformation.

\textbf{Challenge:} Choose a system that undergoes major change (career,
institution, technology). Use the 8D Essence triad
(Identity $\rightarrow$ Continuity $\rightarrow$ Coherence) to show how its
identity persists across apparent discontinuities.

\textbf{Win Condition:} You articulate a coherent essence that survives change
and can distinguish between superficial and structural transformations.

\subsection{Trial VII: The Unity Test (9D)}

\textbf{Theme:} Integration of multiple dimensions.

\textbf{Challenge:} Build a cross--scale model that integrates at least three
macro dimensions (for example, 5D Meaning, 7D Mind, 8D Essence) and their
micro echoes. Anchor the model in 9D Unity.

\textbf{Win Condition:} You show how 9D Unity reframes or stabilizes the entire
system, and you can explain how the integrated model behaves differently from
any of its parts in isolation.

\medskip
Passing the Dimensional Trials is not a one--time event but an ongoing
practice. Each revisit deepens the researcher's grasp of the Sandbox and
extends the canon for future contributors.
```
