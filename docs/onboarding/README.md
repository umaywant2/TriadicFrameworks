## 🧭 How to Begin

1. Clone the repo and run `validate_manifest.py`
2. Complete `initiation_ritual.md`
3. Submit a PR and earn your first badge
4. Add yourself to `honor_roll/contributor_honor_roll.md`

Badges are symbolic credentials—not rewards. They mark resonance, not rank.
