# 🌍 **Purpose of This Module**

Public Support is the **outreach layer** of TriadicFrameworks.

It exists to:

- help newcomers understand the canon  
- provide transparency for supporters  
- offer structured ways to contribute  
- host validator dashboards for public clarity  
- coordinate launch events and partner outreach
