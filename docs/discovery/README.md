# 🔍 Discovery — Exploratory Visuals & Scroll Galleries

The `discovery` directory contains exploratory documents and scroll‑based galleries used to reveal emergent structures, loopholes, and conceptual artifacts within TriadicFrameworks.

Discovery modules are intentionally playful, investigative, and visually driven.  
They help readers uncover:

- hidden structural patterns  
- resonance anomalies  
- loophole behaviors  
- scroll‑based conceptual reveals  
- early‑stage experimental ideas  

These files are not formal specifications — they are **exploration spaces**.

---

## 📄 Included Discovery Files

### `loophole_scroll_gallery.md`
A scroll‑based gallery showcasing loophole behaviors, resonance artifacts, and conceptual anomalies.  
Used for discovery, experimentation, and visual exploration of RTT and cross‑domain mechanics.

---

## 🧩 How to Reference Discovery Modules

Inside any module:

```md
See: `docs/discovery/loophole_scroll_gallery.md`
```

Or include directly:

```md

```

Discovery modules keep your documentation **curious**, **experimental**, and **drift‑aware**.
