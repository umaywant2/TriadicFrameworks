OpenAPI Suite

Name disambiguation: openapi in this canon does not refer to the OpenAPI Specification (OAS/Swagger) REST-schema standard used to describe HTTP APIs. It refers to the TriadicFrameworks open-aperture principle — a domain module that exposes its signature, operators, drift surface, and lineage hooks to cross-domain inspection. The prefix Open in OpenLLM, OpenIAM, OpenRisk, etc. signals aperture, not REST compliance.

The OpenAPI Loop

1
READ SIGNATURE
Confirm the module's identity contract: dimension_vector, coherence_threshold, operator_affinity, ring assignments.
2
SCAN SIBLING METADATA
Compare all Open* modules for axis mismatches against this module's declared dimension_vector.
3
CLASSIFY DRIFT
Assign drift type and severity: SEMANTIC · REGIME · TEMPORAL · COHERENCE · IDENTITY · ACCESS · SCHEMA · THROUGHPUT.
4
APPLY OPERATOR
Select from the module's operator affinity list and execute using canonical grammar: VERB(subject, target, [modifier]).
5
WRITE LINEAGE
INDEX the lineage note in lineage/<module>/<timestamp>.md via OpenData. Loop is closed only when lineage is written.
