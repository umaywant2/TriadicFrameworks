# MightyTHOR Agents

The **agents** directory contains Thor‑specific agents that orchestrate resonance, overlays, and integrations.  
These are higher‑order processes compared to [agent‑shell bots](../../agent_shell/bots/).

## Structure
- Resonance agents → manage glyph/fold orchestration
- Overlay agents → feed data into dashboards
- Integration agents → connect Thor to external systems

## Purpose
Agents are the **hands of Thor**.  
They coordinate resonance flows, trigger overlays, and extend TFTincryption into distributed contexts.
