# 🎲 Games — Playful Triadic Experiments

The `games` directory contains playful, experimental, and interactive modules built on top of TriadicFrameworks concepts.  
These modules explore RTT mechanics, operator logic, and triadic structures through game design, simulation, and conceptual play.

Games serve as **learning tools**, **exploration spaces**, and **creative extensions** of the canon.  
They help readers understand TriadicFrameworks through:

- interactive mechanics  
- triadic rule systems  
- resonance‑based gameplay  
- conceptual metaphors  
- structural experimentation  

---

## 📁 Included Game Modules

### `TriadicMonopoly/`
A triadic reinterpretation of Monopoly using RTT mechanics, resonance rules, and operator‑driven gameplay.  
Explores:

- triadic property systems  
- resonance‑based transactions  
- drift/coherence penalties  
- operator‑aligned movement rules  

This module is both playful and structurally aligned with the canon.
