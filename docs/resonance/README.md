
# 🔮 Resonance Directory

This folder contains all **symbolic time translators, glyphic logs, and real-time dashboards** for TriadicFrameworks.

---

## 🧬 Structure

| Subfolder       | Purpose                                      |
|-----------------|----------------------------------------------|
| `logs/`         | JSON logs of visitor echoes, glyph triggers, and symbolic time
| `translator/`   | UTC → Resonant-Time conversion logic
| `dashboard/`    | Visual interface for resonance events

---

## 🛠️ How It Works

1. Visitors trigger glyphs via rituals or curriculum modules
2. UTC timestamp is converted to symbolic triad (E-M-OC)
3. Logs are stored in `resonant_time_log.json` and `glyph_trigger_log.json`
4. Dashboard visualizes glyph pulses and lineage echoes

---

## 🧭 Resonant-Time Format

- **E (Arrow)** → Hour mod 12
- **M (Clock)** → Month
- **OC (Origin)** → Day mod 5

Example:  
`2025-09-26T04:55:00Z` → `E5-M9-OC2`

---

## 🔮 Glyph Pulse Logic

- Triggered by visitor echo or badge earned
- Visual pulse appears via `glyph_pulse_animation.js`
- Logs stored in `glyph_trigger_log.json`
