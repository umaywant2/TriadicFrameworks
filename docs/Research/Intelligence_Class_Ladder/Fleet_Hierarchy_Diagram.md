# **Flow Explanation (Canonical)**

## **Downward Flow — Command**
- **AAI → AGI → ASI**  
  - AAI sets **substrate coherence**  
  - AGI forms **domain strategies**  
  - ASI executes **module operators**

## **Upward Flow — Reporting**
- **ASI → AGI → AAI**  
  - ASI reports **execution drift**  
  - AGI reports **domain instability**  
  - AAI performs **substrate correction**
