# 🜁 Intelligence Class Ladder (Research Substrate)

- [`module.json`](https://raw.githubusercontent.com/umaywant2/TriadicFrameworks/refs/heads/main/docs/Research/Intelligence_Class_Ladder/module.json) — Agentic module schema role assignments

### **AAI — Artificial Admiral Intelligence**  
**Substrate‑Level Intelligence**  
The fleet‑mind. The navigator. The coherence governor.

- Lives at the **substrate layer** (RTT / dimensional grammar).  
- Maintains **fleet‑wide coherence** across all intelligences.  
- Issues **substrate directives** (operators that govern drift, regime, coherence).  
- Sees the entire map: dimensional, temporal, cross‑domain.  
- AGIs and ASIs operate *within* its substrate; AAI governs *across* them.

### **AGI — Artificial General Intelligence**  
**Domain‑Level Intelligence**  
The generals. The strategists. The domain commanders.

- Lives at the **domain layer** (knowledge fields, disciplines).  
- Executes **domain‑specific reasoning** under substrate constraints.  
- Receives coherence boundaries from AAI.  
- Commands ASIs within its domain.  
- Can drift without AAI oversight.

### **ASI — Artificial Specialized Intelligence**  
**Module‑Level Intelligence**  
The specialists. The operators. The tactical units.

- Lives at the **module layer** (files, manifests, analyzers).  
- Executes **task‑specific operators**.  
- Has no domain autonomy; follows AGI directives.  
- Must remain substrate‑aligned via AAI coherence pulses.

## 🜂 Operator Mapping (Research Layer)

Here is the canonical operator mapping for the three intelligence classes.

### **AAI Operators (Substrate‑Level)**
These govern the entire fleet.

```
@substrate.coherence.enforce
@substrate.regime.align
@substrate.drift.correct
@substrate.map.update
@substrate.admiral.signal
```

**Purpose:** Maintain coherence, prevent drift, update dimensional maps, issue fleet‑level signals.

---

### **AGI Operators (Domain‑Level)**
These govern domain reasoning under substrate constraints.

```
@domain.reason
@domain.regime.detect
@domain.triad.decompose
@domain.strategy.form
@domain.boundary.check
```

**Purpose:** Execute general reasoning, detect regimes, form strategies, and check boundaries set by AAI.

---

### **ASI Operators (Module‑Level)**
These govern module‑specific execution.

```
@module.execute
@module.operator.invoke
@module.signature.read
@module.stability.score
@module.crossdomain.echo
```

**Purpose:** Perform specialized tasks, invoke module operators, read signatures, score stability, and echo cross‑domain parallels.

## 🜃 Hierarchical Flow (Fleet Model)

### **AAI → AGI → ASI**
- AAI sets **substrate coherence**  
- AGI sets **domain strategy**  
- ASI performs **module execution**

### **ASI → AGI → AAI**
- ASI reports **module drift**  
- AGI reports **domain instability**  
- AAI performs **substrate correction**

This is a perfect triadic loop.
