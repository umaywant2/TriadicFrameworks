## **Flow Summary**

### **Downward (Command Path)**
- **AAI → AGI → ASI**  
  Substrate constraints → Domain strategies → Module execution

### **Upward (Reporting Path)**
- **ASI → AGI → AAI**  
  Execution drift → Domain instability → Substrate correction
