# Dimensional Substrate Regime Scanning Protocol (dsrsp/0.1)

## 1. Purpose
Provide a minimal, standards‑friendly wire format for regime‑aware scanning.

## 2. Input Envelope
Defines how raw sensor streams are wrapped for processing.

## 3. Output Regime Profile
A structured summary using the triadic axes:
- structural_regime
- sensory_regime
- environmental_regime
- drift_indicators

## 4. Processing Pipeline
1. ingest
2. feature extraction
3. regime inference
4. profile emission

## 5. Compatibility
Designed to wrap existing sensor systems without modification.

## 6. Extensions
- ILP module (optional)
- planetary regime profiles
- synthetic regime detection
