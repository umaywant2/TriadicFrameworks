# Models

## 1. Model Identity
Defines what the model is, what it tracks, and what it excludes.

- name  
- purpose  
- boundaries  
- assumptions  

---

## 2. Model Shape
Describes the structural form of the model.

- primitives  
- structures  
- dimensions  
- topology  

---

## 3. Model Regimes
Coherent modes of operation.

- regime identity  
- constraints  
- gradients  
- transitions  

---

## 4. Model Operators
Actions and transformations applied to the model.

- transformations  
- evaluations  
- comparisons  
- compositions  

---

## 5. Model Validation
Ensures coherence and structural integrity.

- coherence checks  
- boundary checks  
- regime checks  
- operator checks
