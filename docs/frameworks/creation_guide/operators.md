# Operators

## 1. Operator Identity
Defines what the operator does and guarantees.

- name  
- domain  
- codomain  
- guarantees  

---

## 2. Transformations
Change the form of the model.

- shape changes  
- dimensional changes  
- regime changes  
- normalization  

---

## 3. Evaluations
Measure or assess the model.

- metrics  
- qualifiers  
- invariants  
- diagnostics  

---

## 4. Comparisons
Relate one model to another.

- equivalence  
- similarity  
- contrast  
- mapping  

---

## 5. Compositions
Combine operators or models.

- sequential  
- parallel  
- triadic  
- meta‑composition
