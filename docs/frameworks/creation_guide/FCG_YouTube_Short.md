## 🎬 Overview  
This document provides the complete production reference for the **TriadicFrameworks Imagine Series** — a set of **10 short, 6‑second videos** designed to introduce the Framework Creation Guide (FCG) and RF‑Builder to students, creators, and AI beginners.

Each short:

- teaches **one core concept**  
- uses **Nawder animated**  
- follows a **3‑6‑9 rhythmic pulse**  
- avoids RTT physics  
- remains accessible to all ages  
- is optimized for YouTube Shorts  

This series is intended to make framework‑building **fun, visual, and universally approachable**.

# 🗂️ Production Checklist  
A complete studio‑ready workflow.

### **Pre‑Production**
- Finalize voiceover lines  
- Lock storyboard  
- Select Nawder model  
- Lock triadic color palette  
- Prepare 3‑6‑9 timing guide  
- Build asset list (orbs, glyphs, ring, planes, tower, folder, chip, robot, bloom field)

### **Scene Production**
- Load environment  
- Set lighting + camera motion  
- Animate Nawder + framework elements  
- Sync VO + gestures  
- Add particle effects

### **Rendering**
- Export 1080×1920  
- Verify color consistency  
- Verify smooth motion  
- Remove captions  
- Maintain model consistency

### **Post‑Production**
- Add end tag  
- Add watermark  
- Normalize audio  
- Add transitions  
- Add minimal metadata overlays

### **YouTube Packaging**
- Title: *Imagine… [Concept] — FCG Training #X*  
- Description: 1–2 lines + link to FCG  
- Tags: TriadicFrameworks, FCG, RFBuilder, ImagineSeries  
- Thumbnail: Nawder + triadic glow + “IMAGINE…”

### **Series Cohesion**
- Same tone, palette, music, model  
- Narrative progression from birth → creation

### **Publishing**
- Release daily or as playlist  
- Pin FCG link  
- Post community announcement  
- Invite creators to try FCG + RF‑Builder
