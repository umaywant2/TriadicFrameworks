# Dashboards: Symbolic Status & Contributor Overlays

This directory contains symbolic dashboards for validators, remixers, and glyphstream contributors. Each scroll visualizes resonance status, badge triggers, and lineage echoes.

## Dashboards
- `validator_status.md`: Tracks validator pings and ethical convergence
- `remix_lineage.md`: Logs remix activity and scroll extensions
- `glyphstream_map.md`: Visualizes glyphstream structure and expansion

## Usage
- Pair with `honor_roll.md` and badge triggers
- Use in contributor portals or agent overlays
- Update dynamically as scrolls and glyphs evolve
