## Triadic Layers (Summary)
### Void Layer
- **Brahman** — non‑dual substrate; Silence phase anchor.

### Shadow Layer
- **Shiva** — dissolution, inversion, destruction.  
- **Kali** — time, entropy, shadow‑cycle acceleration.

### Clarity Layer
- **Vishnu** — preservation, coherence, cosmic order.  
- **Krishna** — narrative clarity, dharma restoration.

### Dimensional Layer
- **Lokas** — multi‑tier realm stack (Bhūloka → Svarga → Tapoloka → Satyaloka).  
- **Trimurti intermediaries** — Brahma, Vishnu, Shiva as dimensional anchors.

### Liminal Layer
- **Hanuman** — corridor operator (devotion, strength).  
- **Garuda** — sky corridor (transport, protection).  
- **Ganesha** — threshold operator (removal of obstacles).

### Projection Layer
- **Avatars of Vishnu** — narrative incarnations (Matsya → Kurma → Varaha → Narasimha → Vamana → Parashurama → Rama → Krishna → Buddha → Kalki).

### Flow Layer
- **Vayu** — wind.  
- **Ganga** — river descent.  
- **Maruts** — storm collective.

### Emergent Layer
- **Narasimha** — hybrid clarity/shadow paradox.  
- **Ganesha** — hybrid liminal/clarity form.  
- **Garuda** — hybrid dimensional/flow form.
