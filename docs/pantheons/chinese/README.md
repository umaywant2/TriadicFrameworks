## **Triadic Operators**
The Chinese mythological system expresses a natural triadic structure through **cosmic separation**, **civilizational continuance**, and **moral/cosmic dissolution**.

| **Layer** | **Operator** | **Role** |
|----------|--------------|----------|
| **Genesis** | **Pangu** | Separates Heaven and Earth; world‑structuring |
| | **Nüwa** | Creates humanity; repairs cosmic order |
| | **Fuxi** | Establishes civilization; trigrams, writing |
| | **Yuanshi Tianzun** | Primordial Heavenly Lord; cosmic hierarchy |
| **Continuance** | **Huangdi** | Governance, medicine, cultural order |
| | **Guanyin** | Compassion, protection, emotional harmony |
| | **Shennong** | Agriculture, herbal medicine, sustenance |
| | **Chenghuang** | Civic protection, justice, social stability |
| **Dissolution** | **Gonggong** | Cosmic imbalance; floods, destruction |
| | **Taowu** | Chaos, malevolence, moral disorder |
| | **Yanluo Wang** | Judgment, punishment, underworld governance |
| | **Huli Jing** | Deception, imbalance, spiritual corruption |
| **Liminal** | **Zhong Kui** | Demon‑slayer; threshold guardian |
| | **Eight Immortals** | Spirit‑world mediators |
| | **Meng Po** | Memory erasure; reincarnation threshold |
| | **Bai Suzhen** | Transformation, love, boundary crossing |

---

## **Structural Notes**
- Genesis is **cosmic separation + civilizational invention**  
- Continuance is **harmonious + protective**, emphasizing governance and compassion  
- Dissolution is **moral + cosmic**, tied to imbalance and corruption  
- Liminality is **spirit‑world dominant**, emphasizing reincarnation and mediation  
- Cosmology is **hierarchical + cyclical**, with Heaven, Earth, and Underworld interlocking
