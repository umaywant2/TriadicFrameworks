## **Triadic Operators**
The Sumerian mythological system expresses a natural triadic structure through **primordial emergence**, **city‑state continuance**, and **chaos‑driven dissolution**.

| **Layer** | **Operator** | **Role** |
|----------|--------------|----------|
| **Genesis** | **Abzu** | Freshwater deep; primordial source of creation |
| | **Tiamat** | Saltwater chaos; mother of early gods |
| | **Lahmu & Lahamu** | First‑born emergent beings; proto‑order |
| | **Anshar & Kishar** | Sky‑horizon and earth‑horizon; cosmic structuring |
| **Continuance** | **Enlil** | Sovereignty, air, kingship, order |
| | **Enki (Ea)** | Wisdom, water, craft, civilization maintenance |
| | **Ninhursag** | Fertility, land, creation of life |
| | **Utu (Shamash)** | Sun, justice, moral continuance |
| **Dissolution** | **Kur** | Underworld chaos; dissolution through imbalance |
| | **Ereshkigal** | Underworld queen; death, separation of realms |
| | **Nergal** | Plague, war, destructive force |
| | **Anzu** | Chaos‑theft of divine order; destabilization |
| **Liminal** | **Inanna (Ishtar)** | Love, war, sovereignty; boundary‑crossing, descent/ascent |
| | **Dumuzid (Tammuz)** | Seasonal death/rebirth; liminal cycle operator |
| | **Geshtinanna** | Dream, fate, seasonal mediation |
| | **Namtar** | Fate‑messenger; underworld transitions |

---

## **Structural Notes**
- Genesis is **primordial + aquatic + emergent**, not anthropomorphic  
- Continuance is **city‑state + ecological + judicial**, emphasizing order and craft  
- Dissolution is **chaos + underworld + imbalance**, tied to cosmic threat  
- Liminality is **descent/ascent + seasonal + fate‑driven**, with strong narrative cycles  
- Sumerian cosmology is **layered**, with clear vertical structure (Heaven → Earth → Kur)
