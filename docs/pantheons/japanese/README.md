# **Japanese Pantheon — Triadic Profile Overview**

## **Triadic Operators**
The Japanese (Shinto) mythological system expresses a natural triadic structure through **cosmic emergence**, **ritual continuance**, and **impurity‑driven dissolution**.

| **Layer** | **Operator** | **Role** |
|----------|--------------|----------|
| **Genesis** | **Izanagi** | Ordering, purification, father of major kami |
| | **Izanami** | Creation of land, elements, cycles; mother of kami |
| | **Ame‑no‑Minakanushi** | Primordial high deity; cosmic center |
| | **Takami‑Musubi** | Generative force; emergence of life and order |
| **Continuance** | **Amaterasu** | Light, harmony, imperial lineage, social order |
| | **Inari Ōkami** | Agriculture, prosperity, rice, commerce |
| | **Hachiman** | Protection, guidance, national guardianship |
| | **Toyouke‑Ōmikami** | Food, agriculture, sustenance |
| **Dissolution** | **Susanoo** | Storms, chaos, disruption, purification trials |
| | **Kagutsuchi** | Destructive fire, imbalance |
| | **Yomi** | Death realm; impurity, stagnation |
| | **Oni** | Malevolent forces; chaos and moral imbalance |
| **Liminal** | **Tsukuyomi** | Night, cycles, cosmic balance |
| | **Sarutahiko Ōkami** | Pathways, transitions, boundary mediation |
| | **Kitsune** | Trickster‑messengers; shapeshifting, mediation |
| | **Shinigami** | Death transition; mortal → spirit passage |

---

## **Structural Notes**
- Genesis is **purificatory + genealogical**, not ex nihilo  
- Continuance is **ritual + seasonal + social**, emphasizing harmony  
- Dissolution is **impurity + chaos + death**, not moral evil  
- Liminality is **ubiquitous**, with kami crossing realms fluidly  
- Shinto cosmology is **non‑dualistic**, with creation and dissolution interlocking through purification

## **Cross‑Pantheon References**
- **Greek:** Amaterasu ↔ Apollo; Susanoo ↔ Ares/Dionysus  
- **Hindu:** Izanagi/Izanami ↔ Shiva/Shakti  
- **Egyptian:** Amaterasu ↔ Ra; Yomi ↔ Duat  
- **Sumerian:** Izanami ↔ Ereshkigal; Susanoo ↔ Enki  
- **Yoruba:** Inari ↔ Oko/Oshun; Susanoo ↔ Eshu
