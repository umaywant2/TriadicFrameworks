- analyze frameworks

# **1. The Five Diagnostic Domains**

Every diagnostic tool in FFT falls into one of five domains:

1. **Operator Diagnostics** — What operators are active?  
2. **Dimensional Diagnostics** — What layers are engaged?  
3. **Regime Diagnostics** — What stability state is the framework in?  
4. **Coherence Diagnostics** — How well does the framework handle paradox?  
5. **Ecosystem Diagnostics** — How does the framework behave in a field?

Each domain has its own instruments.

# **2. Operator Diagnostics**  
### *Tools for identifying operator patterns and activation levels*

---

## **2.1 Operator Activation Scan**

```
Check B → L → R → T → E → H → C
Mark: Active / Weak / Suppressed
```

This scan reveals:

- dominant operators  
- missing operators  
- suppressed operators  
- operator imbalance  

---

## **2.2 Operator Load Test**

```
Increase paradox → observe operator response
```

Healthy frameworks:

- activate T‑Ops under stress  
- activate E‑Ops under context shift  
- activate H‑Ops under oscillation  
- activate C‑Ops under paradox  

Unhealthy frameworks collapse into B‑Ops or L‑Ops.

---

## **2.3 Operator Drift Detector**

Detects when a framework is drifting toward:

- over‑structuring (B/L dominance)  
- over‑motion (T dominance)  
- over‑contextualization (E dominance)  
- over‑rhythm (H dominance)  
- over‑integration (C dominance)  

Operator drift predicts collapse.
