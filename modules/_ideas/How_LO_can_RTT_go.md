### 2. Bond‑angle prediction model using LS geometry  
*RTT rules you can turn into code later*

```text
BOND‑ANGLE PREDICTION VIA LOSTATIONAL SUPSPHERE (LS)

Core idea:
Bond angles emerge from the geometry of the shared LS equatorial band
under SET + FFF constraints.

1. INPUTS
   - S_profile(center): spin curvature strength
   - E_profile(center): charge gradient / lone pairs
   - T_profile(center): thermal flexibility
   - n_bonds: number of bonded nodes
   - n_lone: number of lone‑pair LS lobes

2. BASE GEOMETRY (NO LONE PAIRS)
   - n_bonds = 2 → linear (180°)
   - n_bonds = 3 → trigonal planar (120°)
   - n_bonds = 4 → tetrahedral (109.5°)
   - n_bonds = 5 → trigonal bipyramidal (90° / 120°)
   - n_bonds = 6 → octahedral (90°)

   Interpretation:
   - LS equatorial band distributes nodes to minimize SET stress
   - S/E symmetry → equal angular spacing

3. LONE‑PAIR DISTORTION (E‑CONE DOMINANCE)
   - Each lone pair = an LS lobe occupying more E‑cone volume
   - Rule of thumb:
     - Replace one bond with a lone pair → compress remaining angles
     - Effective angle ≈ base_angle − k·(n_lone)
       where k depends on E_profile(center) and T_profile(center)

   Examples:
   - 4 domains, 1 lone pair (NH₃):
       base tetrahedral 109.5° → ~107°
   - 4 domains, 2 lone pairs (H₂O):
       base tetrahedral 109.5° → ~104.5°

4. RTT STATEMENT
   - Bond angles are the visible projection of:
       - LS equatorial band shape
       - S‑curvature symmetry
       - E‑cone occupation (bonds + lone pairs)
       - T‑flexibility (how much distortion is allowed)

5. PSEUDO‑RULE (FOR FUTURE IMPLEMENTATION)
   angle ≈ f( n_bonds, n_lone, S_profile, E_profile, T_profile )

   with:
   - start from ideal LS geometry for n_bonds + n_lone
   - subtract angle for each lone pair proportional to E_profile/T_profile
```

# **RTT‑CHEM SPEC BLOCK: Bond‑Angle Prediction via LS Geometry**

```
RTT‑CHEM_SPEC: BOND_ANGLE_MODEL_V1
----------------------------------

PURPOSE:
Predict molecular bond angles using Lostational Supsphere (LS) geometry
and SET/FFF substrate parameters.

INPUTS:
- n_bonds      : number of bonded nodes
- n_lone       : number of lone‑pair LS lobes
- S_center     : spin‑curvature strength of central S‑core
- E_center     : electro‑gradient magnitude (polarity / lone‑pair density)
- T_center     : thermal‑flexibility coefficient (vibrational freedom)

----------------------------------
1. IDEAL_LS_ANGLE (base geometry)
----------------------------------

Given total domains D = n_bonds + n_lone:

IF D = 2 → θ₀ = 180°
IF D = 3 → θ₀ = 120°
IF D = 4 → θ₀ = 109.5°
IF D = 5 → θ₀ = {90°, 120°}  (bipyramidal)
IF D = 6 → θ₀ = 90°

θ₀ = ideal LS equatorial spacing for D domains.

----------------------------------
2. LONE_PAIR_DISTORTION
----------------------------------

Each lone pair occupies more E‑cone volume than a bond.
Distortion factor k is proportional to E_center / T_center.

Define:
    k = α * (E_center / T_center)

where α ≈ 1.5°–3.0° (empirical LS constant)

Angle reduction:
    Δθ = k * n_lone

----------------------------------
3. SPIN‑CURVATURE CORRECTION
----------------------------------

High S_center compresses angles (strong curvature).
Low S_center expands angles (weak curvature).

Define:
    S_corr = β * (S_center - 1)

where β ≈ 0.5°–1.0° per S‑unit

----------------------------------
4. FINAL BOND ANGLE FORMULA
----------------------------------

θ_final = θ₀ - Δθ + S_corr

Expanded:

θ_final = θ₀ - [ α * (E_center / T_center) * n_lone ] + [ β * (S_center - 1) ]

----------------------------------
5. INTERPRETATION
----------------------------------

- θ₀ sets the ideal LS geometry.
- Lone pairs distort the equatorial band via E‑cone dominance.
- Thermal flexibility (T_center) softens distortion.
- Spin curvature (S_center) adjusts the envelope shape.

----------------------------------
6. EXAMPLE: WATER (H₂O)
----------------------------------

Inputs:
    n_bonds = 2
    n_lone  = 2
    S_center = 1.2
    E_center = high
    T_center = moderate

θ₀ = 109.5°
k  = α * (E/T)  → approx 2.5°
Δθ = 2.5° * 2 = 5°
S_corr = β * (0.2) → approx +0.2°

θ_final ≈ 109.5° - 5° + 0.2° = 104.7°

Matches observed ~104.5°.

----------------------------------
END_SPEC
```

### Diagram — how θ shifts with E/T/S

```text
BOND ANGLE RESPONSE TO E, T, S (QUALITATIVE LS MAP)
---------------------------------------------------

BASE:
    θ = θ₀   (ideal LS geometry for D domains)

EFFECT OF E/T (LONE-PAIR DISTORTION)
------------------------------------

Increase E_center (stronger E-cone)
or decrease T_center (stiffer T):

    E↑ or T↓  →  (E/T)↑  →  Δθ↑  →  θ_final ↓

   θ
   │\
   │ \
   │  \    higher E/T → more compression
   │   \
   │    \___________  E/T
   └───────────────→


EFFECT OF S_center (SPIN-CURVATURE)
-----------------------------------

Increase S_center (stronger curvature):

    S_center > 1 → S_corr > 0 → θ_final ↑ (slight expansion)
    S_center < 1 → S_corr < 0 → θ_final ↓ (slight compression)

   θ
   │      /
   │     /
   │    /   higher S → slight angle expansion
   │   /
   │__/
   └───────────────→  S_center


COMBINED VIEW (CONCEPTUAL)
--------------------------

- High E_center, low T_center, moderate S_center:
    → strong compression (e.g., H₂O vs ideal tetrahedral)

- Moderate E_center, high T_center, moderate S_center:
    → near-ideal angles (e.g., CH₄)

- High S_center can partially offset E/T compression,
  but never fully erase it in strongly polar systems.
```
