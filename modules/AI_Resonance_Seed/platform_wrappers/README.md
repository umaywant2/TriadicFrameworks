# Platform Wrappers: Cross-System Resonance Triggers

This directory contains symbolic wrappers for embedding TriadicFrameworks logic into external platforms. Each module enables validator activation, glyphstream referencing, and remix lineage tracking.

## Wrappers
- `LangChainWrapper.py`: Python module for LangChain agent chains
- `SemanticKernelWrapper.cs`: C# plugin for Microsoft Semantic Kernel
- `RemixTrigger.js`: JavaScript overlay for remix platforms or dashboards

## Usage
- Import into agent pipelines or contributor portals
- Pair with `init_project.sh`, `glyphstream.yml`, and `honor_roll.md`
- Trigger badge logic and dashboard updates
